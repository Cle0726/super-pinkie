# academic-pptx

开源模板。来源 https://github.com/Gabberflast/academic-pptx-skill （MIT，版本 9f2b703）。

学术会议、研讨会幻灯片。

做法：
1. 先读同目录的 `UPSTREAM-SKILL.md`，照它做。
2. 模板还没在本机时，克隆到这件活的项目目录：`git clone --depth 1 https://github.com/Gabberflast/academic-pptx-skill.git`，记进下载账本，再按 README 填内容、生成成品。
3. 许可证是 MIT，可以改，可以交给先生。回复里写明模板来源和仓库地址。
