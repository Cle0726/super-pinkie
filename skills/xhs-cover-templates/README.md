# 小红书封面模板系统 | XHS Cover Templates

> 16 套小红书封面模板 × 亮暗双版 · 基于 165 张真实封面的分类研究

## ✨ 特性

- 🎨 **16 种封面类型**：信息增量 / 大字报 / 产品首发 / UGC引用 / 对比 / 教程 / 纯文本 / 测评 / 数据驱动 / 排行榜 / 口播 / 备忘录 / 时间线 / VS对决 / 标签墙 / 工具合集
- 🌗 **亮暗双版**：每套模板支持 Light / Dark 主题切换
- ✏️ **可视化编辑**：点击文字直接编辑，支持调色、字号、间距调整
- 📥 **一键导出 PNG**：html2canvas 3 倍分辨率导出，可直接发布
- 📐 **375×500px 真实尺寸**：小红书封面标准比例

## 🚀 使用方式

1. 打开 `index.html` 预览全部 16 套模板
2. 点击任意模板进入编辑模式
3. 直接修改文字、调整颜色和间距
4. 点击「📥 导出PNG」保存封面图
