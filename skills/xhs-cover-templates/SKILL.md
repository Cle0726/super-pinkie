# 小红书封面模板（16 套 × 亮 / 暗）

来源：Beatatata/xhs-cover-templates（MIT），原样收录，没有改动。

## 怎么用

1. 先看这个文件夹里的 `塔塔的封面分类研究.md`，按内容类型挑一个：
   - 数据卡片 `01`
   - 观点金句 `02`
   - 产品首发 `03`
   - UGC 引用 `04`
   - 对比型 `05`
   - 教程型 `06`
   - 数据对比 `07`
   - 工具测评 `08`
   - 金句海报 `09`
   - 清单型 `10`
   - 对话气泡 `11`
   - 数据面板 `12`
   - 时间轴 `13`
   - 对决 `14`
   - 标签墙 `15`
   - 卡片堆叠 `16`
2. 把选中的 html 复制到这次活的文件夹，只改里面的文字和数字，不改版式和配色变量（要换颜色只改它顶部的颜色变量）。
3. 截图出图：竖版 3:4，1080×1440。有 `look-page` 就用它；没有就用 `playbooks/web-and-ui.md` 里的截图脚本，把视口设成 1080×1440。
4. 打开出好的图亲眼看：字有没有溢出、有没有被截断、手机上看不看得清。字太多就删字，不要缩到看不清。
5. 一次拿不准用哪套时，挑 2–3 套各出一张，并排给先生选。
