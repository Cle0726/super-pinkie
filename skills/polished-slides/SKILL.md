# polished-slides

开源模板。来源 https://github.com/parahall/polished-slide-visuals （MIT，版本 8f6f6ab）。

把幻灯片做成设计师级版式。

做法：
1. 先读同目录的 `UPSTREAM-SKILL.md`，照它做。
2. 模板还没在本机时，克隆到这件活的项目目录：`git clone --depth 1 https://github.com/parahall/polished-slide-visuals.git`，记进下载账本，再按 README 填内容、生成成品。
3. 许可证是 MIT，可以改，可以交给先生。回复里写明模板来源和仓库地址。
