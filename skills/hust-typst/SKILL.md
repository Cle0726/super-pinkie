# hust-typst

开源模板。来源 https://github.com/werifu/HUST-typst-template （MIT，版本 7e1fd47）。

华中科技大学毕业论文 Typst 模板。

做法：
1. 本文件夹是入口说明，模板文件在上游仓库里。
2. 模板还没在本机时，克隆到这件活的项目目录：`git clone --depth 1 https://github.com/werifu/HUST-typst-template.git`，记进下载账本，再按 README 填内容、生成成品。
3. 许可证是 MIT，可以改，可以交给先生。回复里写明模板来源和仓库地址。
