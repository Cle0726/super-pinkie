# jinba-pptx

开源模板。来源 https://github.com/carnot-tech/jinba-consulting-pptx-skill （MIT，版本 5e781b4）。

咨询公司风格的可编辑 PPT。

做法：
1. 先读同目录的 `UPSTREAM-SKILL.md`，照它做。
2. 模板还没在本机时，克隆到这件活的项目目录：`git clone --depth 1 https://github.com/carnot-tech/jinba-consulting-pptx-skill.git`，记进下载账本，再按 README 填内容、生成成品。
3. 许可证是 MIT，可以改，可以交给先生。回复里写明模板来源和仓库地址。
