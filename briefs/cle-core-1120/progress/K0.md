## §1 发布包实际版本与基准

使用 [v2.5.51 官方发布](https://github.com/Cle0726/super-pinkie/releases/tag/v2.5.51) 的两个 ZIP，不读本机正式 App。先用官方 URL 的 HTTP 206（核对 `Content-Range` 中的文件总长度）读取中央目录和对应条目，用 Python `zipfile` 解压并校验条目 CRC。分别保存到本批隔离目录 `range-evidence/macos-package.json`、`range-evidence/windows-package.json`：

| 发布包 | ZIP 内清单路径 | 原文片段 | ZIP 中 dist 路径数 |
|---|---|---|---:|
| macOS | `超級碧琪.app/Contents/Resources/SuperPinkie/runtime/openclaw/package.json` | `"name": "openclaw"`、`"version": "2026.7.1-2"` | 9179 |
| Windows portable | `超級碧琪/_internal/runtime/node_modules/openclaw/package.json` | `"name": "openclaw"`、`"version": "2026.7.1-2"` | 9179 |

Mac ZIP 的顶层名称在无 UTF-8 标志的读取器中可能显示成 CP437 乱码；路径按原 UTF-8 字节解码。两个包版本一致，**接管基准锁定为 `v2026.7.1-2`**，不选移植报告里的 `v2026.10.4`。官方附注 tag `be8b8a9e8838f832e4fa47cde8bea0a33aec71ba` 解引用到 `0790d9f593ad30c940ed93b5872a8cf6d6f3cf8c`。整包 SHA-256 及 dist 逐文件比较仍在进行；CRC 不替代整包 SHA-256。
