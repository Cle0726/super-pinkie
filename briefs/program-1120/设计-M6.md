## 一、用户看到什么

在 Metre 引擎台（外部引擎跑的那段对话）里：

1. **每一条「你说的话」旁边**，在这一轮已经跑完、而且引擎为这一轮留了检查点的时候，多一个小键「回到这一轮之前」。
   - 引擎还在跑（有 activeRun）时，这些键都是灰的，旁边写「先停下再回退」，按了不动（`aria-disabled`，`tabIndex = -1`，和 #161 一样不进 Tab 序列）。
   - 草稿文件夹不是 git 仓库、引擎没留检查点（`turnCount === 0`）时，不画这个键，不瞎猜。
   - 引擎服务版本太老、不认回退命令时，也不画（见第三节「探测」）。
2. **点了先弹确认**，不直接动手。确认框写：
   - 「回到第 N 轮之前：第 N 轮和之后的对话会撤掉，引擎在这几轮里改的文件会还原。」
   - 下面列这几轮改过的文件和 +/− 行数（用引擎自己算的「从第 N−1 个检查点到现在」的差异）；
   - 两个键：「回到这一轮之前」「算了」。默认焦点在「算了」上，Esc 等于「算了」。
3. **确认后**：
   - 引擎台上第 N 轮及以后的对话消失，输入框里放回第 N 轮你说的那句话（方便改了重发）；
   - 草稿文件夹里的文件回到第 N 轮开始前的样子；
   - 右上提示「已回到第 N 轮之前」；
   - 「改动」面板（`pinkie.engines.diff`）跟着刷新，只剩前 N−1 轮的改动。
4. **失败时**（引擎拒绝、文件夹被别的程序占着等）：提示一句人话原因，对话和文件都不动；不出现引擎服务的名字。

不做：从某一轮「分叉出一段新对话」、回退之后再「重做」。这两样要的话另开一项。

## 三、要不要内核

**不要。** 检查点和回退都是引擎服务（T3 Code，MIT）自己的能力：每一轮跑完它在草稿文件夹的 git 里留一个检查点（`checkpoints[].ordinalWithinScope`，桥已经在用它算 `turnCount` 和整段差异，`engines-bridge.mjs:285`、`:896-904`；草稿文件夹 `git init` 在 `:806`）。碧琪这边只是在桥上多发一条命令、界面上多一个键，不改网关内核、不写 `patch/apply-*.mjs`，cle-core 不用动。

**探测（写代码前第一件事）**：Mac 上现在没装引擎服务，回退命令的确切名字和参数没法在本机核对。我记得是 `orchestration.dispatchCommand` 的 `{type: 'thread.checkpoint.revert', threadId, turnCount}`，但**没有核对过**。开工时先在隔离目录（`/tmp/superpinkie-engines`，不碰 `~/.openclaw`）装一份引擎服务，从它的协议定义里确认命令名、参数、回退后 projection 怎么变（对话是删掉还是标记、输入框回填的文本从哪拿）。核对不上就停下来回这个 PR 报告，不硬写。
桥按「命令被拒 → `canRevert: false`」处理老版本，界面据此不画键。

## 四、怎么测

全部在隔离环境，不碰正式 App、`~/.openclaw`、18789 正式网关和 `/Applications`。

1. **桥（`tests/metre-engines-checkpoint.test.mjs`，新）**：沿用 `tests/metre-engines-bridge.test.mjs` 的假引擎服务（记下每次 `call`，回假 projection）。
   - `revert({turnCount: 1})` 发出的正好是一条回退命令，参数对；回来的是新的 `thread()`；
   - 反例：有 activeRun 时拒绝、不发命令；`turnCount` 为 0、负数、大于当前轮数时拒绝；没有 checkpoints 时 `canRevert` 为 false；引擎服务拒绝命令时报人话、`canRevert` 变 false；
   - `revertPreview` 调 `getFullThreadDiff` 的 from/to 对；
   - 网关方法 `pinkie.engines.revert` / `revertPreview` 注册了，参数都转成字符串/数字。
2. **界面（`tests/metre-engine-checkpoint-ui.test.mjs`，新，真浏览器，假网关）**：照 `tests/metre-engine-upstream-ui.test.mjs` 搭页面。
   - 跑完的轮有键、在跑的时候键灰且不进 Tab 序列；没检查点时不画；
   - 点键先弹确认框，列出文件；按「算了」/ Esc 不调 `pinkie.engines.revert`（反例）；确认后才调，参数是那一轮的轮次，输入框回填那句话；
   - 失败时提示原因、对话不变；
   - WebKit 按 `Alt+Tab`、Chromium 按 `Tab`，确认框焦点先在「算了」，能走到「回到这一轮之前」；

3. **真跑一遍（手工，记进 PR）**：隔离引擎服务 + 隔离网关，草稿文件夹里让引擎跑两轮各改一个文件，回到第 2 轮之前：第 2 轮的对话没了、第 2 轮改的文件还原、第 1 轮的改动还在、`pinkie.engines.diff` 只剩第 1 轮。
