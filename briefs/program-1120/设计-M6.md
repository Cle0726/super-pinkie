## 〇、现在有什么、缺什么

- **对话侧有**：
  - 「从这里分出去」（`ui/injections/laolao-session-cards.js:228`）：新开子会话，继承到某条消息为止的记录（`services/mode-architecture/session-lineage.mjs:455` `trimChildFork`，用 `SessionManager.createBranchedSession(forkAt)`）。**不恢复文件**，原会话也不动。
  - 网关的 `sessions.compaction.restore` / `sessions.compaction.branch`（`desktop/windows/mac-runtime/openclaw/dist/sessions-UcKjjh_n.js:941`、`:1011`）：只能回到**压缩检查点**（上下文压缩时才有），不是每一步都有；也不碰文件。
- **文件侧没有接口**：网关不给文件快照。碧琪插件里现成能用的只有：
  - `before_tool_call` / `after_tool_call` 钩子（`services/mode-architecture/index.mjs:1185`、`:1212`）；
  - `toolTargetPaths()`（`services/mode-architecture/evidence-rules.mjs:225`）：从 write / edit / apply_patch / exec 参数里取出要写的路径（exec 是保守提取）；
  - `RoleMutationAuditor` 的目录前后对比（`services/mode-architecture/metre-roles.mjs:1123`，按 mtime + size，跳过 `node_modules` / `.git` 等）。它只知道「哪些文件变了」，不存原内容，还不了原。

所以要补的是：**每一步动手前，把要被改的文件的原样存下来**；回退时把文件和对话一起拨回去。

## 一、用户看到什么

1. **每条「你说的话」旁边**，这一轮跑完、而且这一轮（或之后）动过文件或对话时，多一个小键「回到这一步之前」。
   - 还在跑时键是灰的，旁边写「先停下再回退」，按了不动（`aria-disabled`，`tabIndex = -1`，和 #161 一样不进 Tab 序列）。
   - 子会话（`:subagent:`）、只读角色会话不画键。
2. **点了先弹确认**，不直接动手：
   - 标题「回到第 N 步之前」，正文「第 N 步和之后的对话会撤掉；这几步里改过的文件会还原。」
   - 下面三组文件：
     - **会还原**：路径 + 「改回原样 / 删掉（这几步新建的）/ 重新放回（这几步删掉的）」；
     - **之后被别处改过**（冲突，见第三节）：默认不勾，勾上才覆盖；
     - **还原不了**：太大没存、在项目文件夹外面、命令行改的但事先没认出来。只列出来，不动它们。
   - 两个键：「回到这一步之前」「算了」。默认焦点在「算了」，Esc 等于「算了」。
3. **确认后**：先还原文件，文件都成功了再撤对话；输入框里放回第 N 步你说的那句话（方便改了重发）；右上角提示「已回到第 N 步之前，还原了 K 个文件」。
4. **失败时**（文件被别的程序锁着、磁盘满、会话正被写）：提示一句人话，**文件和对话都保持回退前的样子**（已经写回去的文件用回退前备份再拨回来）。

不做：重做（回退之后再「前进」）、从某一步分叉并带上文件（「从这里分出去」照旧只带对话）、Metre 引擎台（外部引擎的文件不走网关的工具调用，钩子看不到，要的话另开一项）。

## 二、文件快照存哪、存什么

**存哪**：碧琪状态目录下 `checkpoints/<sessionId>/`（和 `boundProjectRoot(…, {stateRoot: pinkieStateRoot()})` 用同一个 stateRoot，不进项目文件夹、不进 `~/.openclaw`），权限 0700 / 文件 0600。

```
checkpoints/<sessionId>/
  index.json                 # 每一步：{step, userMessageId, startedAt, endedAt, files:[…]}
  blobs/<sha256>             # 文件原样，按内容去重
  before-restore/<时间戳>/   # 回退前把当前内容先备一份，24 小时后清
```

**只记本步改过的文件**，不拍整个文件夹：

- `before_tool_call`：对 `write` / `edit` / `apply_patch` / `code_edit`，用 `toolTargetPaths()` 取路径；**这一步里第一次碰到**某个文件时，把它当前内容存成 blob，记 `{path, existed, preHash}`（不存在就记 `existed: false`，回退时删掉）。同一步里再改同一文件不再存。
- `exec` / `run_tests`：先对 `toolTargetPaths()` 提取到的路径照上面存原样；再借 `RoleMutationAuditor` 的前后对比找出「变了但事先没认出来」的文件，记成 `{path, unrecoverable: 'exec'}`——**说实话列进「还原不了」**，不假装能还原。
- `after_tool_call` / `agent_end`：给每个文件记本步结束时的 `postHash`（冲突判断用）。
- 只收**绑定的项目文件夹和这个会话的工作区里面**的文件；外面的、符号链接、`.git` / `node_modules` 里的只记路径不存内容，列进「还原不了」。

**大小上限**（先定这几个数，写进常量，测试里覆盖）：

| 项 | 上限 | 超了怎么办 |
|---|---|---|
| 单个文件 | 2 MB | 不存内容，记 `unrecoverable: 'too-large'` |
| 一步合计 | 20 MB | 这一步后面的文件同上 |
| 一个会话合计 | 100 MB，且最多留最近 30 步 | 从最老的一步删起；被删掉的那几步的「回到这一步之前」键不再画 |
| 全部会话合计 | 1 GB | 按最后使用时间删整个会话的检查点 |

会话删除 / 归档时一起删它的 `checkpoints/<sessionId>/`。

## 三、回退时冲突怎么办

回到第 N 步之前 = 对第 N 步及以后碰过的每个文件，取**最早那一步**存的原样写回去。

- **冲突**：文件现在的哈希 ≠ 最后一次碰它那一步记的 `postHash`，说明之后被人或别的程序改过。确认框里单列，默认不勾、不覆盖；勾了才覆盖。
- **写回去的做法**：先把所有要动的文件的当前内容备到 `before-restore/`，再逐个「写临时文件 → rename」。任何一个失败，就用 `before-restore/` 全部拨回来，报错，对话不动。
- **对话**：文件全部成功后，在会话写锁下（`acquireSessionWriteLock`，和 `trimChildFork` 同一套）把记录截到第 N 条「你说的话」之前；截完把 `index.json` 里第 N 步及以后删掉。
- **在跑就拒绝**：有活动的一轮时，桥直接拒绝，不动文件也不动对话（界面上键本来就是灰的，这是兜底）。

## 四、要不要内核

**不要。** 全部在碧琪插件里做：
- 文件快照用插件已经能挂的 `before_tool_call` / `after_tool_call` / `agent_end` 钩子；
- 截对话用插件已经在用的 `SessionManager` + `acquireSessionWriteLock`（`session-lineage.mjs:440-475`）；
- 网关方法由插件注册。

不改网关内核、不写 `patch/apply-*.mjs`、不用刷新 `desktop/windows/mac-runtime/`，cle-core 不用动。
不用 `sessions.compaction.restore`：它只能回到压缩点，粒度不对。

局限（写进 PR，不瞒）：只有经过网关工具调用的改动能还原；命令行里没认出来的写入、用户自己在编辑器里改的、引擎台外部引擎改的，都只能列进「还原不了」或「冲突」。
