## 下一轮先写清楚的视觉标准（建议方向，自己判断后定稿再画）

波纹：
- **用户 11-16 补充（最要紧）：「点击背景要有 3D 起伏的感觉」**。不是平面上扩散的一圈线，而是**地面真的鼓起来、落下去**：波峰隆起、波谷凹下，看得出高低。做法上要同时有：①整块像素按高度场上下错位（波峰处的木缝、倒影、地板边线明显拱起，位移比现在大）；②明暗跟坡度走（迎光坡亮、背光坡暗，像浮雕）；③近处起伏幅度大、远处小（透视）；④起伏带着上面的东西一起动（谱台脚、椅子随波轻轻上下一两格，灯闪），这样才有空间感。验收时看动图 / 连续几帧，必须一眼看出「鼓起来」。
- 物理模型：地面是一层很浅的水 / 镜面蜡面。波 = 高度场，用法线做两件事：①折射位移（取倒影和木缝的像素按坡度错开，位移最大 3–4 格，近处大、远处小）；②高光（坡朝向灯光的那面亮，背面暗），亮色取**附近光源的颜色**（舞台口冷蓝、谱台灯各自的颜色），不是统一一个蓝。
- 透视：椭圆纵横比、波长、位移幅度、传播速度都按深度（离地平线的距离）缩放；远处的圈要更细更密。
- 波阵面要是连续的像素线（2px 格下 1–2 格宽，实心，不靠抖动出点），抖动只用在衰减的尾巴上。
- 遮挡：只在地板像素上画；碰到谱台脚 / 椅腿 / 指挥台时，波在后面断开，物体底部亮一线，灯闪一下（已有）。
- 点在空中：想清楚因果（建议：光点从点击处掉到正下方地面，落地起波；掉落 3–4 帧）。
- 节奏：可以考虑对齐 ♩=72 的拍子（落地在下一个半拍），和「指挥」的题材呼应。
- 性能：只重画包围盒（`putImageData` 的 dirty rect），不用 `requestAnimationFrame` / `setInterval`（单测禁止）；减少动态效果时不出现。

像素细节：
- 每样东西先定色阶（5–6 档）和受光方向（舞台口冷光从远处来，谱台灯暖 / 状态色从上来），再画。
- 近排谱台：谱纸的纸张层次（翻起的页角、夹子）、灯罩的形状、金属杆高光。
- 舞台里：顶上一排吊杆灯、台板的透视缝、天幕的渐变，M 节拍器的刻度和摆杆。
- 扩散板降噪：要么更规整的格子（QRD 扩散板的阶梯块），要么干脆减成护墙嵌板 + 一条暗腰线。

## 视觉标准（11-16 白天定稿，先写后画；验收逐条对）

### A. 点击波纹：「打过蜡的台板被点了一下，地面鼓起、落下，一圈圈荡开」

**A1 一个相机、一个地面。** 不再用拍脑袋的椭圆纵横比。地面是一个真的平面，用和地板木条同一个灭点（`vpx = stageX`，`vpy`）的针孔相机投影：
- 屏幕行离灭点的距离 `d = y − vpy`，最底行 `d = Dm`。地面坐标 `X = (x − vpx)·Dm/d`，`Z = f·Dm/d`，`f = 1.5·Dm`（最底行一个圆的竖向半径约为横向的 2/3，越往远越扁）。
- 单位：最底行 1 个地面单位 = 1 格。高度 `h` 也用这个单位，投影到屏幕上往上抬 `h·d/Dm` 格。
- 这样「近大远小、远处更扁、更细、走得更慢、起伏更小」全部由投影自动得到，不另调。

**A2 波 = 高度场，地面真的上下动。**
- 每次点击是一个从落点向外走的「墨西哥帽」波包 `ψ(u) = (1 − u²)·e^(−u²/2)`，`u = (r − R(t))/σ`：一圈隆起的波峰，前后各一道凹下的波谷；240ms 后再跟一个 0.55 倍的第二圈。
- 落点那一刻先「鼓」起一个包（前 60ms 长起来），波峰离开后中间塌成一个坑，再慢慢回平。
- 参数（最底行格）：波速约 95 格/秒、略收尾；`σ ≈ 7`（随时间略变宽）；最大高度 4 格；随半径按 `1/√(1 + r/24)` 衰减、随时间按 `e^(−t/700)` 衰减，1.3 秒前收到 0。
- 多次点击的高度直接相加（两圈相遇会叠高 / 抵消）。

**A3 画法：像素自己起伏（不是在画上叠一圈线）。**
- 从远到近一行行画地板（画家算法）：每个地板像素按自己那点的高度抬到 `y' = y − h·d/Dm`；两行之间拉开的空当用近的那行填满；近处的波峰抬起来会**盖住**它后面的地面（真遮挡）。木缝、木纹、台阶沿、倒影、灯在地上的光斑全都跟着拱起来、弯下去。
- 屏幕最底下往下多算 8 行，近处的波峰抬起来时底边不露空。

**A4 明暗跟坡度走（浮雕）。**
- 用高度场的坡度算受光：光从**舞台口**（远处、正前方）来，再加每盏**亮着的谱台灯**和**指挥台灯**（各自位置、各自颜色、按距离衰减）。朝光的坡亮，背光的坡暗。
- 屏幕上的结果：每道波峰 = 下面一条背光的暗带（朝着我们的那面）+ 顶上一条细亮线（翻过去朝舞台口的那面）；波谷反过来。这是「上亮下暗 = 凸起」的读法，一眼就是鼓起来的。
- 亮线的颜色取附近的光：舞台口附近是冷蓝，跑着的谱台灯旁是钴蓝，做完的是暖白，出错的是砖红，指挥台旁是暖黄。不是全场一个蓝。
- 深色：地板调亮一档（现在的地板几乎全黑，暗带没处可暗），暗面往下压 1–2 档，亮面往光色推 2–3 档。浅色（墨线版）：亮面推到纸白，暗面压一档灰，波峰顶是一条墨线（颜色同样取附近的灯：钴蓝 / 砖红 / 石墨）。
- **量化**：明暗分 5 档（暗 2、暗 1、原色、亮 1、亮线），波还强的时候是实心色块、实心线，不抖动；只有衰减到一半以下时才用 Bayer 抖动淡出。

**A5 东西跟着波动，空间才立得起来。**
- 谱台、椅子、指挥台按它们**脚下**那点的地面高度上下移（同一个投影，自然是近处移得多：中排 1–2 格、远排 ≤ 1 格；指挥台最多 1 格，台上的谱台跟着台子走）。
- 遮挡：东西按脚的深度排进画家顺序。近处抬起的地面能盖住远处谱台的脚，谱台也挡住它后面的波。
- 波峰扫过谱台脚：那盏灯闪一下（灯芯变亮 + 一圈小光晕），立杆最底下一两格被光色打亮一下。一圈一圈往外传，像一拍传到各个声部。

**A6 落点和「空中」点击的因果。**
- 点在地板上：落点溅起 6 颗光点（地面坐标里往外、往上抛，受重力落回，250ms 内），**每颗光点正下方的地面上有一个暗的影子点**，影子和光点之间的距离就是高度——这是空间感最直接的证据。
- 点在谱台 / 椅子 / 指挥台上：波从它的脚下起，它的灯马上亮一下。
- 点在上面的空处或后墙上：不再画空中光环。从点击处掉下一颗光点（加速下落，160–320ms，按距离），拖一段运动残影（残影可以抖动），快落地时地上它的落点先亮起一小片（光照到地面上），落地才起波、溅光点。落点在点击处正下方的地面中段；对话页避开输入框（落在输入框上沿以上）。
- 节拍：**不**等半拍对齐（点了要马上有反应，延迟会像卡顿）；节拍的呼应留给谱台灯的闪（波峰传到哪盏亮哪盏）。

**A7 节制。** 一次点击 1.3 秒结束；最多同时 6 个；对话页整体对比度降一半，但波纹只降 0.2（不然看不见）；减少动态效果时完全不出现；不用 requestAnimationFrame / setInterval（33ms 的 setTimeout，波纹结束就停）；每帧只把画面重画的那几行（地板 + 被移动的东西）贴回画布。

### B. 像素细节：「有光、有材质、有秩序，不噪」

每样东西先定色阶和受光方向：主光 = 舞台口的冷光（从远处正前方来，离舞台口越远越暗）；局部光 = 谱台灯（从上往下，各自颜色）。浅色主题是墨线版：同样的结构，用墨色线条和纸白表达，不是反相。

- **B1 后墙上半**：规整的竖向吸音木条（4 格一根：3 格面 + 1 格缝），每 7 根一道嵌板缝；木条的亮度只由「离舞台口多远」决定（4 档，舞台口两边最亮），不再随机深浅（不要条形码）；往上用抖动淡进大厅的暗。腰线一条亮边 + 一条暗缝。
- **B2 护墙嵌板**：凸起的嵌板，斜面受光方向朝着舞台口（舞台口左边的嵌板右上斜面亮、左下暗；右边的反过来）。
- **B3 地板**：6 档色阶（比现在亮一档）；木条朝灭点收拢；木纹只在近处；舞台口在地上的倒影和光；台阶沿是一条亮边 + 一条暗边。
- **B4 舞台里**：天幕是从上到下 5 档的冷色渐变，靠近台面的地方有一道「地平线」的亮；檐幕下面一根吊杆，吊着一排小灯（灯罩 + 灯口），每盏往下打一道很淡的光锥（抖动）；台面是有透视缝的木板，被光照亮；M 节拍器：底座上刻度，摆锤有一根摆杆连到底部支点（摆杆跟着摆锤动）。
- **B5 近排谱台**：谱板上两页纸有厚度（下面再露一层纸边），右上角一个翻起的页角（亮面 + 背面阴影），上沿中间一个夹子；灯罩是有弧度的梯形（顶上一线高光、侧面暗），灯口一行亮；立杆左边一线金属高光。不亮的灯也能看出是金属灯罩。
- **B6 每处画完用 `CROP=… 6` 放大检查**：不留孤立的单个像素、不留锯齿错位、不出现两种材质之间的脏色。

## §A 作废，重新设计（11-16 用户看了第十二稿）

用户原话：「你这个不是 Metre 的风格的视觉来设计的点击效果，你这个明显是硬加根本没有设计」。

**为什么不对**：第十二稿是一个通用的「水面波纹」——平滑 30 帧、渐变明暗、蓝紫色光、溅水珠、掉光点。这些东西在任何产品里都可以有，和 Metre 已经定下来的视觉语言一条都没关系：
- Metre 的东西都**按拍子跳格**（♩=72，半拍一步；过场里「落在格子上一步一步跳，只在换格时重画」），没有平滑运动；
- Metre 的「波」是**方的、按格子走的声波**（切换过场里摆锤每拍推出一圈方形声波）；
- Metre 的强调只有**一个钴蓝**，留给「这一拍 / 现在」（落拍的指挥棒是一列钴蓝的点、当前拍点、指挥线上的音符）；其余是墨 / 纸的中性色；
- Metre 的节奏单位是 **强-弱-弱-弱**（四个拍点、1 2 3 4）；
- 画面里本来就有的立体语言是**台阶沿**：一线亮边 + 一线暗边（地板上那两道 risers）。

## §A′ 新设计：「落拍」——你点的是一个强拍，地板一块块按拍子跳起来

**一句话**：点一下 = 指挥落下一个强拍（拍点 ictus）。排练厅的地板是一块块木地板，被点的那一块先弹起来，然后一圈圈方形的「声波」沿着地板的木条格子往外走，走到哪块，哪块就跳起来、再落下；一共四圈，强-弱-弱-弱。走过谱台脚下时，那个声部的灯亮一下——像一拍传到各个声部。

**每一条的来由（都来自 Metre 已有的东西，不新造）**
1. **格子 = 地板本身的木条**：圈不是画上去的线，是真的那几块木板在动。木板用画面里已有的透视木条（同一个灭点、同样宽），沿长度方向按固定长度分块、相邻两条错开半块（真的地板是错缝铺的）。圈的形状是在木板格子里的「方形距离」（切比雪夫距离）——就是过场里那种方形声波，只是铺在透视的地面上。
2. **按拍子跳格**：一切只在 ♩=72 的三十二分音符格点上变（104ms 一步），步与步之间不补帧。全局对齐同一个时钟，所以和节拍器摆锤、指挥台灯在同一张拍子网格上。
3. **强-弱-弱-弱**：四圈，每隔一个十六分音符（2 步）发出一圈。第一圈（强拍）抬得最高；后面三圈一圈比一圈低。
4. **立体 = 台阶沿的语言**：一块木板抬起 L 格，它朝我们的那条边就是一个新的「台阶沿」：最上一线亮边（鼻线），下面 L 格是暗的立面；抬起来的板面整体亮一档（离灯近）；板面落下去（波后面那一圈会沉下一点）时，后面那块的立面露出来——就是「鼓起、落下」。近处一块板抬 4 格，中段 2 格，远处 1 格（同一个透视）。
5. **只有强拍那一圈用钴蓝**：第一圈的鼻线是钴蓝（深色 `#93A5EE`，浅色 `#2F4BB0`，和过场 / 指挥棒同一个色）；后三圈的鼻线是中性墨色。不用渐变光、不用状态色以外的颜色。
6. **东西跟着板子走**：谱台、椅子、指挥台站在哪块板上，就跟着那块板上下（同一个格数，整格跳）；近处抬起的板会挡住后面东西的脚。强拍那一圈走到谱台脚下，那盏灯按它自己的状态色亮一步、再半亮一步（不亮的灯亮成暖白 / 浅色的钴蓝）。
7. **点在谱台上** = 点那个声部：从它脚下那块板起拍，它的灯立刻亮。
8. **点在上面的空处 / 后墙上** = 指挥棒落下：一列钴蓝的点（和过场「落拍」那根指挥棒一样，隔一格一个点）从点的地方往下画，两步画到地板，第三步落在地板上那一块（这一步起拍、棒子从上往下收掉）。不再有「光点下落」、溅水珠这类通用效果。

**量化的规格**
- 一步 `TICK = 60000/72/8 ≈ 104ms`；整个效果 13 步（约 1.35 秒）；指挥棒多 2 步在前面。
- 第 k 圈（k = 0..3）在第 2k 步发出，第 s 步时半径 `r = s − 2k`（单位：木板块），最远 6 块。
- 每块板的高度：正好在圈上 = `A_k`，刚走过（里面一圈）= `−0.4·A_k`（沉一点），别处 0；`A = [3, 1.6, 1.3, 1]`，随半径按 `1 − r/8` 收。几圈相加。
- 屏幕上抬的格数 `L = round(h · 1.4 · d/Dm)`（d = 这一行离灭点的距离），整数。
- 颜色：鼻线（强拍钴蓝 / 其余中性墨）、立面（深色 `edgeLo`，浅色 `bevLo`）、抬起的板面往亮里推一档、沉下的板面往暗里压一档。别的不加。
- 减少动态效果时不出现；只用 setTimeout，按全局拍子格点排下一步；每步只重画改动的那几行。

**验收**
- 单看一步的截图：能看出是哪几块木板抬起来了（有台阶沿）、强拍那圈是钴蓝的鼻线。
- 连续几步：一圈方的波一格一格往外走，四圈有强弱；谱台跟着它脚下那块板跳。
- 和过场（`laolao-metre-transition.js`）摆在一起看：是同一个东西（方形声波、钴蓝指挥棒、跳格）。

**三层**
- **趣味（错视）**：看着是一片平的黑，点一下才发现它是一张纸，而且能被压下去、弹起来。全是平面手法造出来的纵深：谱线往一点收拢（透视）、坑里越深越暗、受光的内壁亮一道、符头陷进去变小、飞出来时和自己在纸上的影子拉开距离。
- **哲思**：这就是「时空弯曲」那张经典图——一张平的网格被一颗有质量的球压弯，平面上第一次看见第三维。谱纸本来就是一张「时空」网格：横的五线是音高，竖的小节线是时间（拍子）。一个音有重量。荡开的涟漪就是「时空的涟漪」（引力波；人类第一次探测到它时，是把它转成一声上扬的「啾」听到的）。
- **双关**：**Metre** 一个词两个意思——拍子（时间的度量）和米（空间的度量）。点「一拍」，压弯的是「空间」。另外「鼓」：纸被压下去又**鼓**起来，像一面鼓。

### 规格
1. **平面的朝向就是空间感**：地板是水平面（保留第十二稿那种透视水波、谱台跟着起伏、灯闪，不改）；地板以上是竖直面，正对着我们——圈是**正圆**，在地平线（墙和地板的交线）处截断。点在哪个面上，波就躺在哪个面里。
2. **谱纸只在「空」的地方显出来**（大厅的暗、画布上方透明处），后墙木条、舞台口本身就是线，直接被弯；谱台、椅子、指挥台在纸的前面，不被弯，纸在它们后面弯。
   - 五线：线距 3 格，一组 5 线，组间空 11 格（周期 24 格）；小节线每 40 格，只在五线之间。整张纸对齐页面（多次点击露出的是同一张纸）。
   - 线色：深色 = 底色往冷光推 20%；浅色（墨线版）= 淡墨。显出的范围跟着涟漪走（圈外没有），淡出只用两档色（实线 → 半色 → 没有），不抖动。
3. **坑（时间线，从落上去算）**：0–100ms 压下去（中心缩到 ~0.5 倍：谱线往坑里收拢），~240ms 弹平，~340ms 鼓起（中心放大 ~1.2 倍），再小小地陷一下回平。形状是「重力井」：中心尖、四周缓（1/(1+r²)），半径约 44 格。
4. **涟漪**：纸弹起来时（170ms）从坑口发出一圈，晚一个十六分音符（208ms）再一圈 0.55 倍的；正圆、往外走、越走越淡，1.3 秒内收完。涟漪经过的地方纸面一高一低（像透镜一样把后面的线推开）。
5. **光**：从左上来（像素画的惯例）。受光坡往冷光（深色）/ 纸白（浅色）推，背光坡压暗；坑底最暗（越深越暗）。明暗 5 档，不抖动。
6. **符头**：钴蓝的实心斜椭圆（左上一点高光、右下一线暗边，是个有体积的「球」）。飞来时 90ms 从 2.6 倍缩到 1 倍；深色主题纸上是它照出的一圈光斑（越近越小越亮），浅色主题是它的影子（从右下滑到它脚下）——光斑 / 影子和它重合的那一刻就是「落上纸」。陷进坑里时跟着变小、变暗；鼓起时变大，然后变成第一颗 ♪ 飞走。
7. **音符**：钴蓝 ♪ + 两颗墨色（♩ / ♫），抛起、飘、晃、最后抖动散掉（一开始那版的动法）；竖直面上每颗音符右下有一个影子（深色是淡的回影），离纸越远影子离得越开——它们是从纸面飞向我们的。
8. 节制照旧：1.3 秒、最多 4 个、33ms setTimeout、减少动态效果时不出现、正文 / 按钮 / 输入框 / 侧栏不触发。
