# Metre 模式 · 注入清点（批 0，A0-1）

- 清点人：Windows 会话（Opus 5.5），2026-11-13。
- 怎么量的：`node tools/metre/inject-inventory.mjs project metre`。把 `mode-architecture`、`project-scope` 两个插件注册到一个假的 api 上，按优先级逐个调用 `before_prompt_build`，记下每个钩子的来源、优先级、产出字数；工作区文件（OpenClaw 自己注入的 bootstrap）按仓库 `personas/<模式>/` 的文件算。状态目录和工作区都在临时目录，不碰正式环境，不调模型。
- 样例消息：「帮我把登录页的按钮改成蓝色，顺便跑一下测试，看看有没有别的地方也要改」（会触发打法、工具箱、活儿卡）。`tests/metre-inject.test.mjs` 另用三条消息（写报告+做页面、你好、起名+海报）断言同样的结论。
- 字数口径：JavaScript 字符串长度（一个汉字算 1）。
