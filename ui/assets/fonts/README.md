# Shared UI font

Noto Sans SC, full variable weight range 100–900. Both desktop bundles use the same local WOFF2 file; no system-font dependency or network request. Code/editor monospace fonts remain separate.

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
