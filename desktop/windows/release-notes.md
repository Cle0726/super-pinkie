## 2.5.49

碧琪这次憋了一个大更新：界面整个翻新，写代码、操作电脑、分头干活都更强了，干活更稳、出错说人话，学习台多了背一背和闯关游戏，设定也有了守护。

- 操作电脑更强：Mac 和 Windows 上都能按名字找按钮、一次连做好几步，做顺了的流程会记下来，下次直接用，少绕好多圈。
- 分头干活更强：碧琪能把独立的活交给子会话同时做，换个模式也行，用的是你选的模型；顶部分工条一眼看清谁在忙什么，做完把完整结论交回来。

- 需要的工具碧琪会自己备好：缺什么先检查再下载，网不好会接着上次的进度下，下完核对完整才用；Windows 上中文路径也不会出错。
- 过程卡更清楚：不再莫名消失，工具都叫中文名并计数，用时算上思考；中途追加消息不再和正在跑的回复撞车，失败重试也不会把你的话发两遍。
- 出问题说人话：回复失败会说清真实原因，并推荐一个能用的模型；输入框上方有运行状态条，断线后自动接上，活干完用系统通知提醒你。
- 第一次配模型更简单：选好服务商一键测连接，出错用大白话说明。正式版会守住碧琪的核心设定，被改了自动复原；更新包带签名，只装官方原版。
- 小修一：碧琪回复时输入框下面的按钮不再跳来跳去；同一句话不会显示两遍，你刚发的话也不会切个页面就不见；刷新后你点过的赞还在。
- 小修二：碧琪的说明书不会再被悄悄截掉后半截；只说「继续」又没东西可接时她会先问你；你点过她的浏览器后，她还能接着用。
- 小修三：Windows 上托盘、快捷提问热键、系统通知和导出原来没生效，现在都好了；窗口右上角按钮不再被挡住，关窗口就真的退出。
- 小修四：侧边栏收起后快捷键能一键展开，长提示不会跑出屏幕；归档前会先停下还在跑的子会话；学习台每个入口都能回到原来的页面。
