## 这次更新了什么

- 新版思考过程：碧琪干活时按段显示「思考了多久」，读了什么、写了什么、跑了什么命令一条条列出来，做完在底部签上「C.le.」落款，写明完成几个步骤、用了多久。
- 右侧栏加了白天/黑夜切换；新增上下文面板，能按类别看占用，一键压缩。
- 追问排队按会话分开，不会串到别的对话；发图片时马上显示你的消息和缩略图。
- 两套思考档位会按活儿的种类走：做 PPT、视频、海报、写作、网页时，各自按对应的方法检查成品，不再只会按写代码的标准检查。
- 更新更可靠：Mac 应用内更新改为跟随正式发布（之前会拉到旧代码）；Windows 便携版更新能真正装上；更新窗口可选国内线路。
- Mac 和 Windows 用同一套界面。
- 碧琪替你写文案、做 PPT 和视频时更老实：你没给的价格、配料、店名会用【】标出来提醒你换成真的，用了图库图片会直说；问「我这电脑能不能做某某」时，会先实际检测一遍再回答；做好的 PPT 会把交给你的那个文件本身转成图片检查。
- 碧琪会做的事更多、做得更好：项目、想法、聊天、学习四个模式都带上了同一套「打法」，碰到视频和动画（配音、字幕、混音）、PPT 和 Word、简历和公文、Excel 和图表、海报和印刷品、文案、App 和小游戏、接 AI 的应用、自动化、放到网上和服务器时，会先按对应的打法做，做完自己亲眼检查再交。
- 碧琪会先摸清你的电脑：做视频、跑大批量这类重活之前，自动检测内存、处理器、显卡、硬盘和是不是在用电池，按你这台电脑的能力定分辨率和做法，并先跑一小段估出要多久。Mac 和 Windows 都支持。
- 项目和想法模式换成「工作优先」的新手册：先把模糊的话补成清楚的任务，直接做、做完验证，长任务先写计划再一直做到完成。
- 更新时会自动换上新手册和新打法；你自己改过的手册文件不会被覆盖，被换掉的旧文件会先备份。
- Windows 更新窗口能看到真实的下载进度。
- 修复 macOS 安装包构建失败的问题。
