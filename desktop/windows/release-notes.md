## 这次更新了什么

- 修复 Windows 上项目、想法、学习和自由模式可能无法切换的问题。
- 修复核心功能插件，以及部分情况下派对和圆桌无法启动的问题。
- 唠嗑模式恢复使用自己的会话。以前误存到派对代理下的唠嗑记录仍保留，但不会自动显示在新的唠嗑会话中。
- 已有的人格文件、项目和上下文会保留；缺少的模式会在启动时自动补齐。
- 缺文件、核心插件没加载、模型地址写错、本机模型代理没开这类问题，不再一直显示「上游波动，碧琪正在自动重试」，而是直接说明原因；真正的网络中断照常自动续接，连续 30 次仍失败才停下提示。
- 修复在旧维护界面里填了「默认模型」后网关起不来、页面一直「等待上游恢复」的问题，已经填坏的配置会在启动时自动修好。
- 修复聊天页两段内置脚本被安全策略拦下的问题（主题初始化和页面卡住时的自动恢复）。
