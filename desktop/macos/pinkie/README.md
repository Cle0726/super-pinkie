# macOS 原生源码分工

`pinkie/Sources` 是碧琪自己的窗口、浏览器和文件预览源码。它以当前已安装的
`/Applications/超級碧琪.app` 内的源码为基线，只叠加了本轮 Markdown 预览候选修复。
默认构建和碧琪的更新脚本使用这份源码；安装包中的旧 `desktop/macos/Sources`
路径仍保留，但内容也来自碧琪源码，供已有修复工具兼容。

仓库原有的 `desktop/macos/Sources` 是 C.le. 的独立源码，供 `CLE_BRAND=1`
和 C.le. 浏览器测试宿主使用。C.le. 的开屏层也由它自己的构建阶段处理，
碧琪的更新流程不再注入它。

本轮没有更新已安装的 App。以后合并安装时必须先重新核对当前安装版和其他
会话的改动，不可用这份快照覆盖后续更新；笔记本 v2 按用户要求由 Claude
另行安装。
