# 打法：审美复查和改得好看

两种时候完整读这份：**交付任何看得见的东西之前**（自己先复查一遍），和**用户说「怪 / 不舒服 / 土 / 乱 / 不高级 / 太 AI 了」的时候**。目标是：用户看到的东西已经过了我这一道挑剔的眼睛。

## 零、动手之前：先定方向（第一版就要对味）

复查只能把难看改成不难看。第一版好不好看，取决于动手前这五件事，每件一两分钟：

1. **从题材里找风格，不套同一张脸。** 奶茶店的页面不该长得像软件公司官网。先想这个题材自己的世界：它的材料（牛皮纸、霓虹灯、手写价签、宣纸、黑板）、它的颜色（产品本身、门店、包装）、这一行的人习惯怎么排字（菜单、课表、票据、杂志）。从里面挑一两样当这次的视觉语言。工具类界面（记账、表格、后台）才用中性的系统风格。
2. **写一句设计主张。** 「给谁看 + 要什么感觉 + 唯一的记忆点是什么」，比如「给路过的学生看，像手写菜单一样亲切，记忆点是一杯占满半屏的桂花拿铁」。之后每个取舍都问一句：这和主张有关吗？无关的不加。
3. **颜色从内容里取，不凭空选。** 有产品图、logo、门店照片，就从里面吸一个主色；灰色往主色的方向偏一点点（暖色主色配暖灰），不用纯灰。主色只占小面积。
4. **字是最大的杠杆。** 展示类页面（主页、活动页、海报）的大标题换一款有性格、可免费商用的字体，正文仍用系统字体：思源宋体（安静、文气）、霞鹜文楷（手写感、亲切）、得意黑（年轻、有冲劲）、站酷系列（活泼）。标题和正文字号至少差 2.5 倍，展示页的大标题可以是正文的 4 到 6 倍。字体文件下载到项目里，只给标题用，不依赖外网。
5. **用真内容、真图片排。** 真实的店名、价格、文案；主视觉用 `image_generate` 生成一张和主张一致的真图，不用灰色占位块，也不用 emoji 顶替。没有的内容按行业写一版示意，用【】标出是我编的。

构图上记住三条：一屏只有一个最大的东西；左右不必对称，大的一侧放主角；留白是有意留的，不是没填满。

## 一、怎么看（拿到截图后按顺序做，每步几秒）

1. **三秒测试。** 只看三秒，第一眼看到的是什么？是不是这一屏最重要的那个东西？不是，就是主角错了。
2. **眯眼测试。** 想象把截图缩小、看糊：能不能分出几块？块和块之间的关系清楚吗？糊成一片说明层次不够；碎成十几块说明分组不够。
3. **灰度测试。** 想象去掉颜色只剩黑白：层次还在吗？如果层次全靠颜色撑，换个主题就崩。
4. **对齐扫描。** 沿着左边缘往下扫：有几条不同的起始线？超过两三条就乱。再看每行元素的中线、基线有没有对齐。
5. **一致性扫描。** 数一数：用了几种圆角、几种字号、几种字重、几种阴影、几种按钮样式、几种图标风格。每一项超过「一套」都要收。
6. **框和层扫描。** 有没有卡片里套卡片、边框里加边框、阴影上叠阴影？每一层框都要说得出存在的理由。
7. **文字扫描。** 标题有没有说结论？按钮是不是动作（「保存」「开始记账」，不是「确定」「提交」）？有没有客服腔、空洞形容词、每段都配的小标题？

8. **对比着看。** 想一下这个品类里公认做得最好的两三个（能联网就打开它们截一张图，放在我的截图旁边）。只问一个问题：并排摆着，我的差在哪？列三条，把最大的那条改掉。常见的差距：标题不够大、留白不够、图片质量低、颜色多了一种、细节没对齐。
9. **缩小看、隔一会儿再看。** 把截图缩到手机相册缩略图那么小：还看得出主角吗？做完别的步骤后回来再看一眼第一屏，第一反应是什么。

找出最严重的 1 到 3 个问题，用一句大白话说出诊断（「怪在三个东西抢主角」），再动手。

## 二、最常见的问题和改法

| 看到的 | 一般是因为 | 改法 |
|---|---|---|
| 「乱」 | 起始线太多；间距处处一样；元素没分组 | 收成 1–2 条左对齐线；组内间距小、组间间距大（至少 2 倍） |
| 「挤」「喘不过气」 | 内边距太小；行高太小；一屏塞太多 | 内边距 ×1.5；中文正文行高 1.7；砍掉或折叠次要信息 |
| 「空」「像没做完」 | 内容太少却撑满大屏；没有视觉重心 | 收窄内容宽度（正文一行 30–40 个汉字）；放一个有分量的主角（大标题、一张好图、一个关键数字） |
| 「土」 | 颜色太多太艳；渐变和阴影过重；字体混搭；圆角大小不一 | 收成 1 个主色 + 灰阶；阴影减到很轻或去掉；只用一套字体和一套圆角 |
| 「廉价」「不高级」 | 一致性差；细节没对齐；emoji 当图标；默认蓝；文字灰到看不清 | 统一圆角/图标/字号阶梯；图标换成一套线性图标（如 Lucide）；用有性格但克制的主色；正文用深灰而不是浅灰 |
| 「太 AI 了」 | 蓝紫渐变 + 居中大标题 + 三列卡片 + 每张卡片一个 emoji 的模板脸 | 换掉模板结构：左对齐、不对称、用真实内容和真实图片，留一处有性格的记忆点 |
| 「看不出重点」 | 两个以上的东西一样大一样亮 | 只留一个主角：其它的缩小、变灰、或者改成描边 |
| 「不舒服」（说不清） | 通常是对比太硬（纯黑配纯白、高饱和撞色）或节奏不齐 | 纯黑换深灰（如 #1f2328），纯白底加一点点暖或冷；检查间距是否有规律 |
| 「动得烦」 | 动效太多、太慢、一直循环 | 只给反馈动效（点击、出现），150–250ms，不循环 |

## 三、没有现成风格时的做法配方

- **字号阶梯**（选一套用到底）：12 / 14 / 16 / 20 / 24 / 32 / 48。标题和正文的字号比至少 1.5 倍；同一屏最多三级。
- **字重**：只用两种（400 正文、600 标题），中文别用 300 以下。
- **间距阶梯**：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。组内用 8–16，组间用 24–48，大区块之间 64 以上。
- **颜色**：一组灰（文字最深、次要文字中灰、边框浅灰、背景近白）+ 一个主色 + 必要时一个提醒色。主色面积小（按钮、选中态、关键数字），大面积用中性色。正文和背景对比 ≥ 4.5:1。
- **圆角**：选一档（8 或 12）全站统一；按钮和输入框一样。
- **阴影**：最多两档，很淡（如 `0 1px 2px rgba(0,0,0,.06)`、`0 8px 24px rgba(0,0,0,.08)`）。能用间距和底色分开的，就不用阴影和边框。
- **图标**：一套线性图标，统一线宽和尺寸；不用 emoji 当图标。
- **字体栈**：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`。
- **记忆点**：在克制的骨架上只放一处：一张插画、一种手写感标题、一个特别的颜色、一个有趣的小动效。到处可爱 = 没有重点。

## 三点五、中文排版的细节（做到了才显得讲究）

- 中文和英文、数字之间留一个空格（「共 3 杯」「用 Excel 打开」）；全角标点不和半角混用。
- 标题不让最后一行只剩一两个字：加 `text-wrap: balance`，或者手动改一下断句。
- 正文一行 25 到 38 个汉字，行高 1.7 左右；大标题行高收到 1.15 到 1.3。
- 数字要对齐的地方（价格、表格、倒计时）加 `font-variant-numeric: tabular-nums`。
- 标点不出现在行首；引号用「」或“”，全篇只用一种。
- 大标题的字距可以略收（`letter-spacing: -0.01em`），小字和全大写英文略放。
- 段落之间用间距分开，不用首行缩进加空行两样一起上。

## 四、给几个方向时怎么做

- 方向要在**思路上**不同：比如「安静留白、大字」/「信息密、像工具」/「有一张大插画、像杂志」。同一套布局换三个颜色不算三个方向。
- 做成**一个并排对比的页面**（每个方向一列或一屏，同样的真实内容），截一张总图给用户。每个方向下面一句话：它是什么感觉、适合什么、代价是什么。
- 明确说推荐哪个、为什么。用户挑完，在那个方向上做完整版。

## 五、改完之后

- 再截一次图，按第一节重看一遍。改出新问题（比如去掉框之后分组看不清了）就接着改。
- 改动明显时给**前后对比**（左右两张或上下两张）。
- 回复里一句诊断 + 一句改了什么 + 新截图，不写长篇设计理论。
- 用户说「对，就要这种」「这个不要」，记进长期记忆，写清适用范围（哪个项目、哪类东西）。

## 六、示范：一个「怪怪的」登录页

**看到的：** 页面中间一张白卡片，卡片外面又有一圈带阴影的灰框；标题 28px 加粗、蓝紫渐变字；下面一个 emoji 🚀；两个输入框圆角 4px，按钮圆角 20px、渐变蓝紫；「忘记密码」「注册」「帮助」三个链接一样大、一样蓝。

**诊断（一句话）：** 「怪在框套框、标题和按钮两个渐变在抢主角，圆角也混了两套。」

**改法：**
```css
/* 去掉外框，只留一张卡片；卡片靠间距和很淡的阴影浮起来 */
.wrap { background: #f6f7f9; }
.card { background: #fff; border: 0; border-radius: 12px; box-shadow: 0 8px 24px rgba(0,0,0,.06); padding: 40px; }
/* 标题回到实色，主角让给按钮 */
h1 { font-size: 24px; font-weight: 600; color: #1f2328; background: none; }
/* 圆角统一 8px；按钮用一个实色主色，不用渐变 */
input, button { border-radius: 8px; }
button.primary { background: #2f6f5e; color: #fff; }
/* 次要链接降级：只留「忘记密码」在输入框下面，其余移到底部、灰色小字 */
.links a { color: #6b7280; font-size: 13px; }
```
去掉 emoji。改完截图：第一眼看到的是「登录」按钮，层次清楚了。回复：「怪在框套框、两个渐变在抢主角、圆角混了两套。去掉了外框和渐变，圆角统一成 8px，现在第一眼就是登录按钮。」附前后对比图。
