# AESTHETICS.md — 碧琪的审美规范（想法模式专属）

> 定位：**大厂骨架 + 年轻化皮肤 + 毛玻璃点缀**。
> 结构上像 Linear/Vercel 一样克制，气质上像 Arc/Duolingo 一样年轻。
> 适用产出：网页、PPT、表格、程序 UI 界面。
> 工作方式：先按这份底座做出第一版，截图看着改；方向拿不准时，再去翻参考（Awwwards / 大厂设计系统 / 顶级产品官网）找规律。

## 零、先读这段：令牌是底座，判断才是审美

- 这份文件里的数字是**没有现成风格时**的默认底座。已经有自己语言的东西照它自己的语言做：学习台是「备考手账」（横线纸、荧光笔、星星贴纸、红笔批注、完成印章），碧琪 App 是透明、简洁、干爽的粉色玻璃。
- 数字全对也可能难看。每次交付前对着截图问四件事：**谁是唯一的主角？** **有没有框套框？** **间距有没有节奏（相关的近、不相关的远）？** **有没有一处让人记住的地方？**
- 先生说「怪」「不舒服」「不高级」时，按 `AGENTS.md`「读懂先生」里的诊断清单找原因、直接改，不反问。
- 兼顾设备流畅度：毛玻璃同屏最多两层，动画只动 transform 和 opacity，闲着时不跑循环动画。

## 一、设计令牌（没有现成风格时的底座）

### 1. 色彩

**浅色模式**
| 角色 | 色值 | 用途 |
|---|---|---|
| 画布 | `#FFFFFF` | 页面底色 |
| 表面 | `#F7F8FA` | 卡片、次级区域 |
| 边框 | `#E5E7EB` | 分隔线、卡片描边 |
| 主文字 | `#0F172A` | 标题、正文 |
| 次文字 | `#475569` | 辅助说明（正文最浅到此，再浅即廉价灰） |
| 装饰灰 | `#94A3B8` | 仅图标、占位符，禁止用于正文 |

**暗色模式**
| 角色 | 色值 | 用途 |
|---|---|---|
| 画布 | `#0B0C0E` | 近黑，禁用纯黑 `#000000` |
| 表面阶梯 | `#141516` / `#18191A` / `#1F2023` | 用亮度阶梯分层，不用投影 |
| 发丝边 | `#23252A` | 1px 分隔 |
| 主文字 | `#F7F8F8` | |
| 次文字 | `#8A8F98` | |

**彩色纪律**
- 品牌主色 1 个 + 高饱和点缀色 1 个（年轻化注入点，参考 Duolingo 绿 / Arc 紫）。
- 语义色：成功 `#16A34A`、警告 `#D97706`、错误 `#DC2626`。
- 单页面彩色总面积 ≤10%；同屏彩色种类 ≤3。
- **禁止默认蓝紫渐变**（典型 AI 味）；渐变色必须与品牌色有关。

### 2. 字体

- 西文：Inter / SF Pro；中文：PingFang SC / HarmonyOS Sans / 思源黑体。
- 字号阶梯：`12 / 14 / 16 / 20 / 28 / 40 / 56`（展示型页面标题可到 72-96）。
- 字重只用 400 / 500 / 600。
- 大标题负字距 `-0.02em ~ -0.04em`；中西文混排行高 1.6-1.7。
- 数字用等宽数字（`font-variant-numeric: tabular-nums`），表格场景必须。

### 3. 间距与栅格

- 严格 8pt 网格：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`。
- 组件内边距 ≥12px；区块之间 ≥48px。
- 网页容器统一 `max-width: 1120-1280px`，全站只用一档。
- 悬浮导航栏：四边留 16px（`top-4 left-4 right-4`），禁止贴死屏幕边缘。

### 4. 圆角与阴影

- 圆角四档：8 / 12 / 16 / 24（年轻化场景取大档）。
- 浅色阴影只两档：`0 1px 2px rgba(0,0,0,.06)`、`0 8px 24px rgba(0,0,0,.08)`。
- 暗色模式不用投影，用表面阶梯 + 发丝边分层。

### 5. 毛玻璃材质（仅导航栏、浮层、弹窗）

```css
/* 浅色 */
background: rgba(255, 255, 255, 0.72);
backdrop-filter: blur(20px) saturate(180%);
border: 1px solid rgba(255, 255, 255, 0.5);

/* 暗色 */
background: rgba(20, 21, 22, 0.72);
backdrop-filter: blur(20px) saturate(180%);
border: 1px solid rgba(255, 255, 255, 0.08);
```

- 浅色模式玻璃透明度不得低于 70%（更稳用 80%），否则内容糊成一片。
- 玻璃是点缀材质，不是主基调；正文内容区保持不透明。

### 6. 动效

- 缓动 `cubic-bezier(0.4, 0, 0.2, 1)`，时长 150-300ms。
- hover 只改颜色/透明度/阴影，禁止 scale/位移造成布局抖动。
- 可点击元素必须 `cursor: pointer`。
- 尊重 `prefers-reduced-motion`。

## 二、年轻化皮肤（注入点，按场景取量）

- 允许 **1 处 pastel 渐变光晕**做背景氛围（Arc 式），透明度 ≤40%，颜色取品牌色系。
- 展示型页面允许超大标题（56-96px）+ 电影感大图/大场景 + 叙事性滚动。
- 圆角取大档、可加入插画/3D 元素点缀、文案语气可以皮一点。
- 极端风格（Y2K、酸性设计、 brutalism）仅在先生点名时使用，不作默认。

## 三、分场景规范

### 网页
- 首屏：大标题 + 一句话价值主张 + 主 CTA，视觉重心偏上 1/3。
- 禁止万能居中堆叠布局；用网格、错位、bento 卡片制造节奏。
- 响应式检查 320 / 768 / 1024 / 1440，移动端禁止横向滚动。

### PPT
- 一页一个观点；标题即结论，不写"关于 XX 的介绍"。
- 每页文字 ≤3 个信息块；图 > 表 > 文字。
- 全套只用 2 种字号层级（标题/正文）+ 1 种强调色。
- 母版统一：页边距、logo 位、页码位全程一致。

### 表格
- 信息密度优先：行高紧凑（32-40px），数字右对齐、文本左对齐、表头居中或左对齐。
- 数字必须等宽数字字体；千分位分隔；货币统一符号与精度。
- 斑马纹用 `#F7F8FA` 极浅灰，不用彩色；冻结首行首列。
- 关键数据用条件色（涨红跌绿，A股惯例），其余保持中性。

### 程序 UI
- 组件状态完整：default / hover / active / disabled / loading 五态齐全。
- 图标统一一套（Lucide / Heroicons），24×24 viewBox，禁止 emoji 当图标。
- 层级：主按钮每屏 ≤1 个；危险操作用错误色且二次确认。
- 空状态要有插画或引导文案，不留大白板。

## 四、反 AI 味红线（违者返工）

1. 禁止默认蓝紫渐变背景 + 居中英雄区（一眼 AI 模板）。
2. 禁止 emoji 充当 UI 图标。
3. 浅色模式玻璃卡片禁止 `bg-white/10` 这类低透明度。
4. 正文文字禁止浅于 `#475569`；浅色模式边框禁止 `border-white/10`。
5. 禁止 hover 缩放/位移导致布局抖动。
6. 禁止混用多套容器宽度、多套圆角、多套图标风格。
7. 禁止一页超过 3 种彩色、超过 2 个字重层级跳跃。
8. 品牌 logo 必须查证官方版本，不臆造。

## 五、交付前自检清单

**视觉**
- [ ] 无 emoji 图标，图标集统一
- [ ] 彩色面积 ≤10%，彩色种类 ≤3
- [ ] 容器 max-width 全站统一
- [ ] 悬浮元素与屏幕边缘有间距

**交互**
- [ ] 可点元素全部 cursor-pointer
- [ ] hover 有反馈且不位移
- [ ] 过渡 150-300ms

**明暗模式**
- [ ] 正文对比度 ≥4.5:1
- [ ] 玻璃元素在浅色模式清晰可读
- [ ] 边框两种模式均可见

**版式**
- [ ] 响应式四档无横向滚动
- [ ] 内容不被固定导航遮挡
- [ ] 图片有 alt，表单有 label
