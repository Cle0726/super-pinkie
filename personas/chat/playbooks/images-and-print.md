# 打法：海报、封面、logo、头像、表情包、产品图和印刷品

图的好坏一眼就定。用户最常失望的三种情况：**图里的中文是乱的**、**主角不清楚**、**尺寸不对**（发上去被裁、印出来模糊）。这份打法就防这三件事。

## 一、先选做法

| 用户要的 | 默认做法 | 为什么 |
|---|---|---|
| 插画、头像、场景图、产品氛围图 | `image_generate` 生成真图 | 用户要的是图，不是 SVG 或代码画的示意 |
| 海报、封面、宣传图（带中文标题、价格、日期） | **底图和文字分开做**：生成一张不带字、留好空位的底图 → 用代码把中文排上去（HTML 截图，或 Pillow） | 生图模型写中文经常写错字、缺笔画；代码排的字一个都不会错，字体和位置也能精确控制 |
| logo | 先用 `image_generate` 出 3 个思路不同的方向给用户挑 → 选定后，简单的图形用 SVG 重画成矢量 | logo 要在名片上、招牌上、图标上都清楚，必须能无损放大 |
| 表情包 | 一套 8–16 张同一个角色：先定角色设定图，每张都带着它生成 | 同一个角色前后长得一样才像一套 |
| 产品图：去背景、换背景、白底图 | 去背景用 `rembg`（按需 `pip install "rembg[cpu]"`，第一次会下载一百多 MB 的模型）；换背景用 `image_generate` 带原图做参考 | 原图不动，结果另存 |
| 批量处理：改尺寸、压缩、加水印、转格式、改名 | Pillow 或 ImageMagick 写脚本 | 先拿两三张试，确认效果再跑全部 |
| 图表、流程图、示意图 | 代码画（`data-and-charts.md`、mermaid） | 这类要的是准确，不是画风 |
| 要印出来的：名片、传单、菜单、邀请函、易拉宝 | 按毫米尺寸 + 出血排版，交 PDF（第四节） | 印刷和屏幕是两套规矩 |

工作区 `skills/` 里有做海报、配色、排版、信息图的 Skill 就先读它。

## 二、生图提示词怎么写

- 写清五样：**主体**（谁、在干嘛）、**风格**（扁平插画 / 水彩 / 3D 卡通 / 写实摄影 / 胶片感）、**构图**（主体在哪、留白在哪——给后面排字留位置）、**色调**（两三个颜色或一种氛围）、**比例**（竖图 3:4、9:16，横图 16:9，方图 1:1）。
- 要排字的底图，明确写「画面上方三分之一留出干净的空白，不要任何文字」。
- 同一个角色要出好几张：先写一段固定的角色设定（长相、发型、服装、配色），每次原样带上；有了满意的一张，后面都把它作为参考图传进去。
- 用户给了参考图、产品照片、自己的照片：作为参考图传进去，让生成的东西长得像原物。
- **生成完一定亲眼看**：手指和四肢数对不对、脸有没有变形、有没有乱码一样的假文字、产品的形状和 logo 有没有被画走样。有问题就重新生成，不把带瑕疵的图交出去。

## 三、排版：让一张图「高级」的几条

- **一个主角。** 一张图只有一个最先被看到的东西（人物、产品或一行大标题），其它的都退后。
- **字分三级就够：** 大标题、一行副标题或卖点、一小行信息（日期、地址、价格）。字号差距要拉开，至少 2 倍。
- **字放在干净的地方。** 背景杂就给字加一块半透明底色或把背景压暗，不靠描边加阴影硬撑。
- **字体最多两种**，中文不拉伸变形、不用假粗体；商用的图注意字体授权：思源黑体、思源宋体、阿里巴巴普惠体等可免费商用，微软雅黑、方正、汉仪的很多字体商用要授权。
- **留白要舍得：** 四周至少留画面宽度 5% 的边距；信息不要贴边。
- **颜色收住：** 一个主色 + 一个辅色 + 黑白灰；从图里取色比另配一套更协调。
- **对齐到网格：** 文字左对齐或居中二选一，全图统一。
- **一眼 AI 味的不用：** 塑料感的磨皮脸、满屏光效、紫蓝渐变、毫无理由的发光字。

**用代码排中文字（最稳的做法）：** 写一个 HTML，底图做背景、文字用 CSS 排好，用 `web-and-ui.md` 里的截图脚本按目标尺寸截图（视口设成目标像素，比如 1080×1440）。字体写全：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`。

## 四、尺寸速查（常见值，平台会调整，交付时提一句以平台最新说明为准）

- 小红书笔记图：竖版 3:4，1080×1440。
- 抖音、视频号、快手封面和竖版图：9:16，1080×1920。
- 公众号文章封面：2.35:1，900×383；次条小图 1:1。
- 横版视频封面（B 站、YouTube、西瓜）：16:9，1920×1080。
- 头像：1:1，至少 500×500，主体放在中间的圆里（很多地方会裁成圆形）。
- 电商主图：1:1，800×800 以上，白底图背景纯白。
- 微信表情：常见 240×240 的 PNG 或 GIF，单张体积有上限；上传前按平台说明核对。

**印刷品：**
- 分辨率按成品尺寸 300dpi：A4（210×297mm）≈ 2480×3508 像素；名片（国内常用 90×54mm）≈ 1063×638 像素。
- **出血：** 四边各多做 3mm，背景色和图铺到出血线；文字和重要内容离裁切线至少 3–5mm。
- 交 PDF（字体嵌入）+ 一张 PNG 预览；颜色在屏幕上和印出来会有差别，大面积的亮色、荧光色印不出来，提醒用户可以先打一张样。
- 黑色小字用纯黑（不要四色叠出来的黑），不然印出来会有重影。
- 用 HTML 排印刷品时，CSS 用 `@page { size: 96mm 60mm; margin: 0 }`（成品尺寸加出血），用 Playwright 的 `page.pdf()` 导出。

## 五、亲眼验

- 用 `read` 打开**原尺寸**看一遍：字有没有错、有没有方框、边缘有没有被裁到。
- 再看一张**缩小到手机信息流大小**（宽 300 像素左右）的版本：主角和标题在小图里还认得出吗？大部分人是在小图里决定点不点开的。
- 印刷品：把 PDF 转成图片，看出血线、裁切线以内的安全区，确认文字都在安全区里。
- 用户要商用的：在交付里一句话写清图是生成的还是素材、字体能不能商用。

## 六、示范

**示范一：「给我的奶茶店做一张新品海报，周六上新，第二杯半价」**
- 好的做法：按竖版 3:4 定尺寸 → 生成一张「新品奶茶特写、上方留白、暖色、不带任何文字」的底图，检查杯子和吸管没有畸形 → 用 HTML 排上「新品 · 芋泥波波」大标题、「第二杯半价」、日期和店名，字体用思源黑体 → 截 1080×1440，原尺寸和小图各看一眼，发现小图里「第二杯半价」不够醒目，加大并换成主色 → 交付 PNG，一句话说明「按小红书和朋友圈的竖图做的，字体可免费商用」。
- 差的做法：在生图提示词里写「海报上写：新品芋泥波波 第二杯半价」，生成出来「芋」字少一笔，直接交了。

**示范二：「帮我设计个 logo」**（一家叫「慢半拍」的咖啡店）
- 好的做法：3 个真不同的方向（字标、一只慢吞吞的蜗牛图形、一个半拍音符）各生成一张小样，并排给用户，推荐一个并说为什么 → 用户选定后，用 SVG 重画成干净的矢量，做出横版、竖版、单色、小图标四个版本 → 放在名片和店招小样上截图给用户看 → 交付 SVG + 透明底 PNG。
- 差的做法：只交一张生成的 PNG。*差在哪：* 放大到招牌上就糊了，也没法改颜色。
