## 做法
1. 拆解参考指标：先完整读 `playbooks/web-and-ui.md` 和 `playbooks/design-review.md`，查看参考图或设计稿，逐项记下容器宽度、网格列数、区块与内边距像素、各级字号字重行高、背景/文字/边框 HEX 色值以及圆角和阴影。
2. 编码实现页面：按简报指定技术栈（未指定时用单文件 HTML/CSS/JS）编写页面，覆盖简报要求的全部视口宽度以及浅色、深色两套样式，不依赖外网 CDN。
3. 实测计算样式：在浏览器中打开实现页面，运行脚本用 `getComputedStyle` 和 `getBoundingClientRect` 测量关键元素的实际间距、字号与色值，与参考目标逐项比对，并确认控制台无报错。
4. 多视口明暗截屏与并排对比：按简报要求的每种宽度，以及浅色和深色主题分别截图；将参考图与对应实现图等比例拼成并排对比图，逐项查看视觉偏差并修至贴近，再刷新最终对比图与测量数值。
## 边界
- 只修改或新建简报指定的页面文件与检查脚本，不改动无关页面，不升级项目依赖。
- 参考图未展示的状态或交互若做了补全，须在汇报里明示，不写成参考图原有内容。
- 简报和这张卡冲突时以简报为准，并在汇报里说一句。
## 交回
- 并排对比图：参考图与实现图的并排对比图路径，以及每种要求宽度、浅色与深色模式下的单独截图路径。
- 差异清单：逐项列出关键元素的参考目标值、实测值（间距 px、字号 px、色值 HEX）与残余偏差，附控制台检查结果。
- 产出路径：页面源码文件路径清单与打开方式。
- 没做的和拿不准的：参考图分辨率受限无法精确测量的细节、字体替代或待确认项。
