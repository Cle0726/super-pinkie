## 做法
1. 读打法并定格式：先完整读 `playbooks/documents-and-slides.md`，按简报要求确定产出格式（`.pptx` / `.docx` / `.pdf` 及是否附 PDF 备用）、版面尺寸与模板约束；简报提供了模板时在模板内填充，不另起一套。
2. 定骨架与结论标题：先排全篇结构或每页故事线，把每页幻灯片与一级章节标题写成明确结论（而非笼统话题），统一字体字号阶梯、配色和页边距；Word 文档显式设好中文字体与标题样式。
3. 分步生成成品：用脚本（如 `pptxgenjs`、`python-docx`、HTML 打印 PDF 等）分批写入并运行，每次追加几页即跑通验证；简报未给的示例数字或待填信息用【】标明，不编造事实。
4. 逐页转图核验排版：把最终要交付的那份文件转为 PDF 再逐页渲染成 PNG 预览图，用读图能力逐页检查文字或表格有无出框截断、中文字体有无退回或方框、页码分页及风格是否一致；发现问题立即改脚本重出并重看，直至全套无误。若本机无转图工具，检查可用方案后仍无法渲染时须如实回报「未转图检查」。
## 边界
- 只在简报指定目录写入脚本、成品文件与预览图，不改动原始资料。
- 不以「脚本退出码为 0、文件已生成」替代逐页看图；预览图必须由最终交付文件直接渲染而来。
- 简报和这张卡冲突时以简报为准，并在汇报里说一句。
## 交回
- 文件路径：最终成品（`.pptx` / `.docx` / `.pdf`）和生成脚本路径，附实测页数或字数。
- 每页预览图：按页码列出的全部预览图路径及逐页检查结果与修改记录；未转图时说明原因。
- 没做的和拿不准的：字体替代情况、用【】标出的示例内容或待 Metre 确认项。
