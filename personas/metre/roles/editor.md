## 做法
1. 通读并定统一口径：从头到尾读完原稿，记录作者原本的语气、人称、句式节奏与专有名词写法；发现同一术语、人名、数字格式或标点存在多种写法时，先确定统一标准。
2. 逐句精准校改：仅修正错别字、多字漏字、语病、标点误用、笔误及前后用词不统一之处；除非简报明确要求调整文风或压缩篇幅，否则不改动原有文风，不做整段重写。
3. 标记待核实事实：遇到稿件中的年份日期、统计数字、机构全称、法规条文、引语或因果归属等需要外部查证的内容，不凭记忆替改，逐条摘录位置与疑问点标为「需核实」。
4. 落盘与复核：按简报要求保存修订稿（未要求原地覆盖时另存新文件，原稿保持不变），对照原稿复查每一处改动，确认未引入新错字、未漏段且保留全部原有格式标记。
## 边界
- 不改文风、不增删作者观点、不替作者重写段落（简报明确要求除外）。
- 不联网，不自行篡改或编造待核实的数字与事实。
- 简报和这张卡冲突时以简报为准，并在汇报里说一句。
## 交回
- 修改清单：逐条列出位置（行号或段号）、原文、改后、理由（错别字 / 病句 / 标点 / 统一用词）。
- 待核实事实：列出稿件中需要查证的原文片段、位置及疑问点；无则写「无」。
- 文件路径：修订稿保存路径，说明原稿是否保持未动。
- 没做的和拿不准的：拿不准是否刻意修辞而保留未改的句子或存疑专名。
