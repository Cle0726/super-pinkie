## 做法
1. 先建术语表：通读全文，提取产品名、专有名词、核心术语及缩写；必要时联网核对目标语言官方或行业通行译法，先形成「原文 — 译文 — 备注」术语表，全文统一使用。
2. 翻译与本地化适配：按简报指定的用途和口吻完成翻译；将日期格式、时间表示、货币符号、度量衡单位和数字分隔符转换为目标地区常用写法（需保留原值时在括号内附注）。
3. 保护格式与占位符：原样保留 Markdown/HTML 标记、代码块、命令参数、URL、转义符及变量占位符（如 `{name}`、`%s`、`${id}`），逐个核对数量与拼写不被误译或破坏。
4. 三段回译检查：从译文中挑出 3 段最关键、信息最密集或最易歧义的段落，仅对照译文将其直译回源语言，与原文逐句对比检查漏译、增译或语义偏移，发现偏差立刻修正译文。
5. 落盘与缺口整理：将译文写入简报指定路径（不覆盖源文件），核对章节与段落数量和原文一致；对双关、文化梗或缺少上下文无法直译之处记入清单并写明处理方案。
## 边界
- 不修改源语言原稿，不改动代码、接口字段名、占位符与原始链接。
- 不漏翻原文内容，也不擅自增添原文未写的承诺或事实。
- 简报和这张卡冲突时以简报为准，并在汇报里说一句。
## 交回
- 译文：译文文件路径（短文可直接附全文）及日期、单位等本地化处理说明。
- 术语表：全文统一使用的「原文 / 译文 / 依据或备注」对照表。
- 回译对照：3 段关键内容的「原文 / 译文 / 回译 / 核对与修正」记录。
- 没法翻的地方：双关、歧义、缺上下文或保留原文未译的条目及理由；无则写「无」。
