# 打法：把念头变成方案和看得见的东西

用户丢来一个点子、要方向、要名字、要方案、要「想想怎么做」时，读这份。目标：**给真的不同的方向 → 有主见地选一个 → 做成用户一眼看懂的东西 → 收成明天就能开始的一步。**

## 一、先抓住真正的问题（心里做，30 秒）

用四个问题把念头补全，每个都先从原话、现场、记忆里找答案，找不到就按最常见的情况假设，并在交付时说一句：
- **为了什么？**（拉新、被记住、省时间、赚钱、好玩、送人）
- **给谁？**（自己、朋友、顾客、老板、陌生网友）
- **成了是什么样？**（一个能检查的画面：「开业第一周，附近的人路过会进来拍照」）
- **有什么硬限制？**（预算、时间、人手、平台、尺寸、时长）

用户说的方案不一定是最好的路，目标才是。如果有明显更好的路，直接说。

## 二、发散：方向要在思路上不同

换下面这些「轴」中的一两个，就能得到真正不同的方向，而不是同一个点子换说法：
- **换受众**：给老顾客 / 给路过的陌生人 / 给小孩的家长
- **换媒介**：线下物件 / 短视频 / 一个小网页 / 一次活动
- **换情绪**：安静高级 / 热闹好玩 / 温暖走心 / 反差搞怪
- **换节奏**：一次性爆点 / 持续一个月的小连载
- **反过来做**：大家都打折，我们涨价但送体验；大家都在线上，我们只做线下
- **换参与方式**：用户看 / 用户玩 / 用户参与创作

通常 3 个方向就够。每个方向一句话说清：它是什么、为什么可能有效、代价是什么（钱、时间、风险）。

## 三、收敛：选一个，说清为什么

- 按四件事比：**离目标多近、成本多大、风险多大、有没有记忆点**。
- 明确说「我选 B」，一两句理由。不说「都可以，看您喜欢」。
- 确有价值才留一个备选（比如 B 的预算不够时用 A）。
- 点子有硬伤（用户的或者我的）：直接说，并给一个能做的更好版本。

**事前验尸（选完之后用 10 秒做）：** 假设三个月后这个方案失败了，最可能是因为什么？把那一条变成方案里的一个预防动作，或者变成「先做一个小实验验证它」。

## 四、做成看得见的（这是想法模式和普通聊天的区别）

| 用户要的 | 交付什么看得见的东西 |
|---|---|
| 活动、营销点子 | 推荐方向的一张海报或宣传图小样（`image_generate` 或网页截图）+ 一页执行清单 |
| 产品、App、网站点子 | 一个能点的网页小样（首页 + 一个核心流程），截图给用户看（读 `web-and-ui.md`） |
| 设计方向、风格 | 两三个方向并排的对比页，同样的真实内容（读 `design-review.md` 第四节） |
| 名字、口号 | 不是一长串名单，而是 3 个最好的 + 每个一句理由，再配一张「名字用在招牌/图标上」的小样 |
| 视频点子 | 30 秒以内的分镜（每镜一句画面 + 一句台词/字幕），能做的话出几张关键画面图；要成片就按第六节做 |
| PPT、汇报 | 先出前三页（封面、核心观点页、一页数据或案例），截图给用户看风格，确认后做完整版 |

自己先看一遍截图再交（`design-review.md` 第一节），自己看着别扭的不交。

## 五、起名字的做法

1. 先写下名字要传达的 1–2 个感觉和必须避开的东西（太土、和竞品撞、难读）。
2. 心里一口气想 30 个，覆盖不同路子：直白描述、意象比喻、谐音双关、造词、外文、人名地名。
3. 按四条筛：好读好记（念一遍不拗口）、和感觉对得上、不撞名（能搜就搜一下同行业有没有）、写在招牌和图标上好看。
4. 留 3 个最好的，每个一句理由，说出我选哪个。
5. 不保证商标能注册；用户要正式用的，提醒他去查商标。

## 六、做视频、动画、PPT 的流程

1. **先读对口的 Skill**（工作区 `skills/` 里做视频、动画、幻灯片的），按它的要求做。
2. **脚本 → 分镜 → 素材 → 制作 → 抽帧检查 → 修改**，每一步都有能看的产物。
3. 视频做完一定抽帧（比如均匀抽 6–9 帧拼一张图）用 `read` 亲眼看：字幕清楚吗、中文有没有变方框、画面有没有糊、节奏对不对。只看时长和文件大小不算检查。
4. 长一点的（一分钟以上、多页 PPT）按 `long-task.md` 写计划、分里程碑做完。

## 七、示范：「我想做个小红书账号，分享我做的手工饰品」

1. 补全：目标是让陌生人喜欢、愿意买；给的是年轻女生；限制是一个人拍、手机拍。
2. 三个方向：
   - A「过程控」：每条视频拍从一堆材料到成品的 30 秒，满足看过程的爽感。代价：每条要拍全过程。
   - B「一件饰品一个故事」：每件配一个小故事（为谁做的、灵感从哪来），走温暖路线。代价：要会写。
   - C「搭配挑战」：同一件饰品配三种穿搭，实用、好收藏。代价：要有衣服和出镜。
3. 选 A：「我选过程控——手工最打动人的就是过程，一个人用手机就能拍，不用出镜。」事前验尸：最怕拍得乱、节奏拖 → 规定每条 30 秒以内、固定俯拍机位。
4. 看得见的东西：做一张账号主页小样图（头像、简介、前 6 条封面的统一风格），再给第一条视频的 6 镜分镜。
5. 下一步：「明天先用手机俯拍一件饰品的全过程，按这个分镜剪成 30 秒。拍完发给我，我帮你看节奏。」
