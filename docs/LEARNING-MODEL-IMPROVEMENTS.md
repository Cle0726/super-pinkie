# 学习模式与模型选择器改进

日期：2026-10-23。代码范围：学习服务、学习工作台、C.le. 与旧版模型选择器。

## 实施计划

1. 修正判分：题组内每题独立提交、结算和更新关联笔记；客观题以服务端校验为准。保留旧单题兼容，填空支持可接受答案，简答显示评分依据。
2. 保存学习证据：将作答记录独立于聊天和题卡展示历史保存；记录答案、把握度、提示使用、反馈、错因与重练关系。纠正误判留下记录，不能由模型静默改写客观题结果。
3. 改进复习：区分独立答对、低把握答对和提示后答对；复习分批，展示剩余数量。错题能重新练习，再检查是否掌握。
4. 连起学习流程：在今日进度中给出可执行的下一步，支持短时专注；明确区分活动目标完成与知识掌握。题卡保留用户答案、展示独立结果与真实资料来源。
5. 调整模型选择器：参考用户截图，采用深色圆角面板、顶部搜索、横排厂商分类、紧凑模型列表、右侧真实上下文容量、金色当前选中标记。默认展示全部模型，常用单独筛选；完整目录滚动浏览，不能用固定 7 条或写死的淘汰名单隐藏网关返回的模型。保留现有推理等级、模型切换和会话保存。
6. 验收：后端使用临时目录与合成学习数据，前端使用隔离浏览器页面。同步安装资源版本；生产参数构建到测试目录，不改写用户已有的插件 manifest 或正在运行的 App。

## 验收标准

| 项目 | 场景与通过条件 |
| --- | --- |
| 逐题结算 | 两道题一对一错，只更新各自关联知识点；未作答/未结算的题不被判为掌握；重复提交与重复结算不重复计数 |
| 判分可靠 | 模型给出与客观校验相反的 Boolean，确定结果保持不变；填空可接受答案生效；简答保留评分依据 |
| 学习证据 | 题卡超过 24 张、重建服务后仍可读作答证据；重练保留来源关系；跨会话请求不能修改其他会话的题目或笔记 |
| 纠错 | 用户可纠正误判，保留原结果和纠正记录；反复纠错/结算不会重复增加学习统计或复习次数 |
| 复习 | 提示后或低把握答对不会直接按独立熟练答对升级；分批有上限，并显示剩余量 |
| 学习工作台 | 题组进度清楚，用户答案在评分后可见；提示使用会提交；今日任务完成与掌握状态分别呈现；继续学习有实际动作 |
| 来源 | 只有真实来源才提供查看入口，能定位已有资料；不生成虚假页码或无效外部链接 |
| 模型样式 | 搜索、厂商分类、模型名称、上下文容量与选中标记符合参考布局；使用实际目录数据，不硬编码截图模型 |
| 模型完整性 | 60 条以上目录全部可达，默认展示全部；无固定条数截断，无硬编码型号隐藏；同名不同 provider/id 保持精确路由，不能默默切换成另一端点 |
| 模型交互 | 搜索与分类组合过滤有效；常用只反映当前/最近使用；点击模型仍保存到正确会话；推理等级仍可调；键盘可操作；上下文未知留空 |
| 适配 | 宽屏与窄屏不出现横向溢出或选项无法点击；无浏览器未捕获异常 |
| 集成 | 学习与模型相关测试、先前聊天修复回归通过；修改脚本语法、安装脚本语法和生产参数打包通过 |

## 使用边界

- 所有学习写入与计时验收使用临时合成数据，没有修改真实学习记录。
- 本机配置有 91 条模型配置条目。配置条目数不等于实时可用模型数；界面以网关目录及其可用状态为准。预览只使用脱敏的模型名称、ID 和公开能力字段，不含凭据。
- 本次更新仓库源码与安装资源；生产参数构建写入验收目录，保留用户原有的插件 manifest 修改，没有替换正在运行的 App。Chrome 验收不能代替安装后的 WKWebView 实机检查。
