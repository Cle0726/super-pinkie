# 第三轮：专升本学习练习与实验

范围：C语言运行和逐步观察、错题复习、电工电子实验、网络排障、数学核验、英语阅读/写作、限时模拟。考纲地图与资料定位由用户自行维护，本轮不改。保留Max/Ultra后端、自定义字体和昼夜动画。

状态：开发中。

## 实施顺序

1. 修复模型列表在白天仍为深色的问题；浅色搜索、分类、选中态与夜间分别验收。
2. 在现有消息题卡和学习工具中接入练习入口，统一持久化、版本检查和可见性释放。
3. 接入真实C编译/运行和数学核验，计算失败、未定义行为、超时与不支持必须如实显示。
4. 完成电路、网络、英语交互，接入已有错题证据，补充限时模拟与恢复。
5. 运行后端、真实编译渲染器和窄屏/主题验收，更新App并核对受保护文件。

## 验收标准

- C代码仅在用户点运行后执行，编译和运行隔离；限制时间、输入输出与并发，禁止读取用户文件、写入宿主目录、联网和启动其他程序。真实输出与逐步演示分开核验，不支持的语法不伪造轨迹。
- 电路数值按实际参数计算，明确理想模型与边界；网络地址、子网和故障由实际配置推导，改配置后旧结果失效。
- 数学使用受限表达式解析与计算工具；区分恒等、条件成立与无法确认，不将数值抽样包装成证明。
- 英语阅读先答题和选证据再核对；写作保留草稿，模型反馈由明确操作触发，不伪装成确定评分。
- 错题记录保留原答、错因、提示使用、复测时间；同日练习和延迟独立复测分开，演示操作不增加掌握度。
- 模拟卷有服务器截止时间、逐题草稿、交卷锁定与恢复；交卷前隐藏答案；主观题未评分时不显示假总分。
- 320px与昼夜主题可用；历史卡片离屏释放内容，不新增后台轮询；关闭实验恢复焦点与聊天滚动位置。
- 模型默认常用、最近6个和所有原有路由不改；Max/Ultra与字体动画受保护文件校验相同。
