# 碧琪的派对空间

从 macOS App 聊天框右侧工具栏的碧琪头像和竖向「派对空间」进入；也可用 App 菜单或 ⌘P 打开。
它是独立群聊页面，不替代原有四个模式。

## 已接入的能力

- 建群，给每个群选项目目录（留空会建立独立目录）。
- 「新建项目文件夹」可输入名称和保存位置，实际创建空目录并选中；同名目录不覆盖。App 支持系统文件夹选择器，也能在访达打开已绑定项目。
- 输入区可选回复模型，按群、按成员独立保存。Codex 通过官方 `model/list` 读取列表，执行时传入 `--model`；碧琪和 OpenClaw 从本机已配置文本模型中选择，使用单次配置副本，不更改全局设置。
- 模型列表不等于上游可用性保证；服务商权限或网络故障仍可能导致调用失败。列表缓存最多五分钟；生图模型和可能另起工具进程的 CLI 后端不会混进工具受限成员的选择器。
- 新任务保存当时选择的模型，之后切换不会改变旧任务；重新派发沿用原任务模型。确认页显示成员、模型、项目和权限，只有明确点「确认派发」才会批准。
- 碧琪负责聊天、拆解目标、提出派工；每项派工都由用户确认。
- Codex 使用本机已登录的 CLI，以 `exec --json --ephemeral` 执行。默认只读；修改项目必须另行确认。
- OpenClaw 成员提供独立文本咨询，不直接调用文件或联网工具。
- 群里显示实际消息、任务状态和可折叠的工具记录；支持搜索、复制、停止任务。普通聊天不自动引用用户上一句话，只有小马之间实际派工及其结果保留引用。
- 成员回复后不再自动调用碧琪复述一遍。旧的自动复述在聊天页隐藏，数据库原文保留；用户主动要求汇总时仍可正常回答。
- 派工显示 `@紫悦`、`@云宝` 等小马名字，内部连接标识不变。旧派工卡只修正程序生成的 @ 前缀，不全局替换代码、引用或模型正文。
- 同群任务串行执行，避免同时改同一个项目；不同群记录与上下文分别保存。
- 顶部大标题栏已移除。右侧成员栏可展开／收起，默认收起并记住状态；收起只留头像和 @ 键，聊天区获得更多宽度。尚未接入的成员仍显示禁用状态，不能假装派工。
- 展开成员栏后，「⋯」可以改名、调整已接入成员，或归档群聊，旁边保留查找消息与刷新连接；在「已归档」中可以恢复，记录和项目文件都不删除。
- 群里还有待确认或进行中的任务时，先完成或取消任务，再调整成员或归档。已有群不能换绑项目，另一个项目请新建群。
- 输入草稿、回复引用和接收成员按群自动保存在当前 App／浏览器中，刷新或重启后恢复；修改项目的授权不会随草稿保存。
- 失败、中断、停止的任务可在「任务记录」重新派发，必须再次确认；不会后台自动重做。停止任务不回滚已经修改的文件，重试前请检查项目状态。
- 网络超时后保留草稿，重发同一条待确认消息会复用消息标识，避免重复派工。消息与任务一起保存，保存失败不留下半条消息。

## 累计用量与费用

派对聊天区上方使用与四模式相同的轻量胶囊：输入、输出、缓存读、缓存写、剩余额度、累计估算费用，不恢复旧的大标题栏。

- 数据来自本机 C.le 已有的接口汇总和配额缓存。四模式与派对显示同一份全局累计，不是当前群独有用量；没有经过该接口的调用不计入。
- 累计存在 `~/Library/Application Support/SuperPinkie/usage.sqlite3`。每次只累加统计增量，刷新、重启或两个页面同时读取不重复累加；统计源开始新周期时接着累计，不清零。
- 金额优先使用 C.le 的 `estimatedCostUsd`，是估算费用，不是已扣款、充值金额或美元余额。旧版没有金额字段时才使用原界面的展示系数估算，提示中明确注明。不会为了数字好看按时间虚增金额。
- 剩余额度显示上游配额缓存的百分比，与累计费用分开；缓存写入、额度等字段缺失时显示「—」，不显示内置示例余额。数据源不可读时保留已存的累计值。
- `services/party/usage.py` 可独立同步数据给四模式，派对通过 `/api/usage` 读取。安装器仅更新已经存在的统计同步脚本并先备份，不新增后台计划任务。
- 只保存汇总数字，不导入聊天原文、账号标识或密钥。浏览器技能用于检查实际胶囊排版、成员栏展开后宽度和派工展示，不改背景素材。

Claude、Gemini、Ollama 暂时显示「待接入」，不能派发任务。安装了它们的桌面 App，并不代表存在可安全调用的接口。
本版不是读取所有桌面 App 历史的抓取器；也不展示模型隐藏思维过程。

## 数据和权限

- 数据库：`~/Library/Application Support/SuperPinkie/party/party.sqlite3`。
- 旧数据库首次升级群聊管理时会先在同目录生成 `before-room-management-*.sqlite3` 备份。
- 草稿存放在该页面来源的本机网页存储中，不同步到其他电脑；清除 App／浏览器网页数据会一并清除草稿，但不删除群聊数据库。
- 默认项目：同目录下 `projects/<群ID>`。绑定已有项目不会搬走或删除文件。
- 模型仍走各成员已配置的服务商，并非离线 AI。
- 只传当前群的摘要和近期上下文，不自动导入其他群和四模式的聊天记录。按所选模型和本机策略到达阈值后自动整理，完整记录保留，详见 [会话自动整理](CONTEXT-MANAGEMENT.md)。
- 上下文隔离不是操作系统安全容器。Codex 只读模式禁止写文件，但不代表它绝对无法读取项目以外的文件。不要选择含敏感信息的目录。
- Codex 禁用用户配置里的 MCP 桥接工具；修改模式关闭沙箱内网络，不自动批准发布、支付或额外权限。
- 主持者与 OpenClaw 咨询成员是两个新建专属 Agent，工具全部禁用。每次执行独立会话；已有四模式人格保持不变。
- 本地 HTTP 服务仅监听 `127.0.0.1:18889`，检查 Host、Origin 和页面令牌，不对公网提供接口。
- 关闭 App 会停止它启动的派对服务和进行中的任务；重新打开保留群记录，但不自动重跑未完成任务。停止不会回滚已产生的文件修改。

## 安装和验证

`install-full.sh` 与 App 首次启动会补齐专属 Agent 配置；已有配置先备份，不覆盖同名 Agent。
派对里统一称呼用户为「铲屎官」，包括入场、消息署名、派工提示和成员每次执行的提示。四模式人格文件不改，项目模式仍称「老板」。

成员只设置名字身份，不注入小马性格、口癖、固定语言、篇幅或写作风格。碧琪／紫悦／云宝／珍奇／柔柔／苹果嘉儿以助手身份自称时使用各自名字，不使用「我」「我们」或平台名，不强制每句话加名前缀。引用、代码、翻译和代写作品保留原本第一人称，不对输出做文字替换。名字及简短规则统一保存在 `services/party/identities.json`，每次新执行都会传入；文件访问边界、Skill 读取要求、派工协议和确认机制仍保留。

安装器仅备份迁移自己创建、内容精确匹配旧模板的两个派对 `SOUL.md`／`IDENTITY.md`：移除旧文风要求与 Vibe，将咨询成员的旧名 OpenClaw 改为云宝。用户自定义或符号链接身份文件不覆盖，其他 Agent、四模式人格及历史消息不改写。备份在 `~/Library/Application Support/SuperPinkie/backups/party-identity-*`；涉及配置名称修改时另外备份原配置。
模型列表与实际执行共用运行环境补齐逻辑，解决从 Dock/Finder 启动时找不到 Node、列表只剩默认项的问题。「刷新模型」会重新读取而不是继续用失败缓存。模型按群、按成员保存，任务创建时固定所选模型；尚未建立群聊或已归档时不可更改。
正常 Git 更新和 App 构建包含派对页面、服务与图片，不包含用户数据库、密钥或私人记录。
安装新版本后，如 App 仍在运行，请先复制尚未发送的重要内容，再退出并重新打开，让派对服务切换到新版。不会为了升级强行结束正在运行的 App。

```bash
python3 -m unittest discover -s tests -p '*_test.py' -v
node --test tests/sidebar-mode-isolation.test.mjs

```

开发预览可以使用其他端口及 `--state-dir` 临时目录，以免污染正式记录。
macOS App 与 Windows EXE 都会随桌面壳启动派对服务；Windows 版使用内置运行时和本机独立记录目录，不要求全局安装 OpenClaw。

四模式选择按键改用高清头像与原生文字，不再把底板和文字烘焙进同一张图片。模式按键及常用新会话、建议、设置、发送按钮统一采用派对入口的半透明奶白底、细亮边、轻阴影；保留录音中和禁用状态。键盘焦点可见，减少动态效果设置下关闭位移动画，不给输入区加遮罩。

派对头像、成员名、时间、普通系统提示与按钮不可选中，包含 macOS WebKit 前缀规则。聊天正文、引用正文、工具/错误详情、项目路径和输入框仍可选择复制；引用署名单独排除，不拦截复制粘贴快捷键或文本输入事件。

四模式的小型工具按钮、会话条目及派对的小按钮默认透明，悬停再显示轻底色和细边；当前会话保留淡色提示。录音、停止、危险操作和模式入口不受影响。键盘焦点继续可见；派对编辑区将焦点描边放在外层圆角面板上，不在文字输入区域画直角框。

紫悦对应 Codex，云宝对应 OpenClaw；珍奇／柔柔／苹果嘉儿分别对应尚待接入的 Claude／Gemini／Ollama。真实连接名称保留在小字中，素材不等于连接已经实现。新提示词记录在 `design/party-space/companion-prompts.md`。

进度按成员列表、素材和群聊页面准备阶段单向推进；页面完成绘制后再结束入场，不靠闪一下图片代替加载。
