# 模式双开的顶栏提醒与控件位置

本轮针对「模式双开 / 模式分屏」。阅读区的拆分视图、两边的模式功能、模型和自定义思考档位均不调整。

## 改动

- 右侧模式的关闭入口移到现有顶栏操作区。学习台页面使用现有侧栏位置，不再让粉色浮动按钮盖住正文或考试倒计时。
- 学习模式聊天顶栏加入考试倒计时、每日分钟目标、连续学习天数、已上课数 / 每日目标课数。只读 `pinkie.learning.desk.today`，不写死截图中的数字，不调用模型。
- 顶栏随实际可用宽度缩短标签；很窄时使用同一顶栏的空位。点击提醒能查看完整数据，Escape 或点击外部收起。
- 当前学习会话退出、换会话或切到学习台时清理提醒；异步返回按会话和代次核对。读取失败保留已同步数据并标记，缺失数据不会伪装成 0。
- 后台工作状态以输入区右边缘定位，不再依赖可能为空或隐藏的操作区。与 `New messages` 同时出现时预留独立位置；展开的详情也保留间距并可内部滚动。换会话时释放输入区观察器。

## 验收标准

1. 主窗口原有模式切换、双开入口和功能按钮保留。关闭入口仅在右侧模式窗口出现，单次操作只发一条关闭请求。
2. 关闭入口使用现有顶栏 / 学习台导航，不在正文上方增加固定浮层或新的一行。
3. 日间、夜间图标和文字可辨认；键盘可以操作。
4. 顶栏数据与学习台接口一致。测试特意使用 34 / 546 天、35 分钟、连续 4 天、1 / 3 节，防止误用截图常量。
5. 360–1680 像素宽度下提醒不会挤压原有操作。较窄时保留考试数据，其余在详情中查看。
6. 来回打开聊天和学习台只有一个关闭按钮。切到其他模式不留学习提醒，旧会话的慢响应不覆盖新会话。
7. 后台状态在折叠、展开及输入区尺寸变化时不遮住输入框或新消息按钮。

## 验证与更新边界

自动检查使用独立本地端口和隔离数据。Chromium 运行当前安装包的完整聊天界面；WebKit 使用安装包原有顶栏组件、完整样式及隔离聊天容器，检查同一组界面组件。没有重载用户正在使用的窗口，也没有向用户会话发测试消息。

验收脚本：`tools/work-panel/dock-exit-acceptance.mjs`。完整结果、截图和安装前后的文件哈希保存在本任务的 `work/dock-exit-round14/`。

安装以当时已装好的 App 副本为底，仅替换本轮的 5 个界面资源及必要的加载 / 缓存元数据；签名前后核对原生程序代码段，安装前再核对整个 App 文件清单，发现并发变更就停止覆盖。保留 Claude 已安装的浏览器、学习台等改动。App 由用户自行重启。
