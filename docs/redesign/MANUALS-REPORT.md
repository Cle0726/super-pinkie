## 3. 重复段落与矛盾规则（只登记，不静默删除）

行号均指**本次改版后**的文件。先给结论：**同一文件内没有完全重复的段落**（脚本按 >20 字符的行做过重复检测，四份 `AGENTS.md` 都是 0 重复）。以下是接近重复和真正矛盾的项。

### C1 · `personas/project/AGENTS.md:36` ↔ `personas/project/SOUL.md:3` —— 称呼规则互相冲突

- `AGENTS.md:36`：「称呼和自称照 `SOUL.md`。……自称「我」；称呼用老板。」
- `SOUL.md:3`：「始终称呼用户为『老板』，不改叫『先生』」。
- 实际文件里 `AGENTS.md` 第 62–75、175、182 行有 8 处「先生」，在营造模式下直接违反上面两条。
- **建议修法**：把这 8 处「先生」统一改成「老板」（第 61–75 行整段组件说明是最主要的战场），并在 `AGENTS.md:36` 后补一句「本手册其余章节的『先生』同指老板」。因为这是称呼规则，建议单独一个 commit，并在提交信息里注明是规则对齐而非重皮。

### C2 · `project/AGENTS.md:146/148` ↔ 同文件 `:81`（以及另三个 `AGENTS.md` 的同一行）—— 证据规则冲突

- 用户指令第 1 条「**立即行动**：不要给出空泛的文字步骤，直接调用原生工具操控电脑执行」和同文件的「用真实证据说完成」「出错先读报错」。
- 真正的张力在自检清单那一行（`chat` 第 84、`project`/`thinking`/`learning` 第 81）：「说『完成、通过、修好』的地方，背后有这一轮真实的运行、读回或预览吗？没有就改口。」与「直接返回任务完成的实际结果与状态」放一起，容易被读成「没验证也先报完成」。
- **建议修法**：不碰用户原文，在上一条自检「说『完成、通过、修好』……」后面补半句：「立即行动不等于立即宣称完成；没跑通就说没跑通。」（四份的位置相同，各自补半句即可。）

### C3 · `thinking/AESTHETICS.md:3` / `:86–91` ↔ `thinking/AGENTS.md:137` —— 引用一致，但与人设有张力

- `AGENTS.md:137` 摘要写「大厂骨架 + 年轻化皮肤 + 毛玻璃点缀」，与 `AESTHETICS.md:3` 的定位行逐字一致（**不算矛盾**，属于必要的摘要重复，建议保留）。
- 但 `AESTHETICS.md:90`「圆角取大档、可加入插画/3D 元素点缀、文案语气可以皮一点」与 `SOUL.md` 的「话少、干幽默、法国极简」并非同一套语汇。
- **建议修法**：本轮按用户要求不动令牌；若要收口，只需在 `AESTHETICS.md:90` 前加一句「这些是**注入点**，一次产出只取一处」，不改任何数值。

### N1 · 分量级近重复：`project/AGENTS.md:17–32` ↔ `:119–128` ↔ `personas/project/SOUL.md:11–18`

- 「先看现场再动手 / 保护已有内容 / 小步验证 / 用证据说完成」在 project 的 `AGENTS.md` 第 17–32 行（做事的方法）、第 119–128 行（项目模式的做法）、`SOUL.md` 第 11–18 行（当前模式的工作台）各出现一次。
- 三处措辞不同、详略不同（方法论 → 场景落地 → 语气），**属于有意的分层重复**，不建议删；若要减重，可把 `SOUL.md` 第 11–18 行的条目改为一句引用「做法见 `AGENTS.md` 的『做事的方法』」。登记而已。

### N2 · 分量级近重复：四个 `AGENTS.md` 的「Skill 每次重新读」

- `project/AGENTS.md` 第 133–141 行（`## Skill 每次都要重新读`，4 条 + 1 行理由）与 `project/SOUL.md` 第 22–30 行（`## Skill 强制重载规则`，5 条）是同一套规则的两种写法。
- 读起来是「SOUL 强制度更高（每次必须）／AGENTS 版本更细（附理由）」，**规则本身一致**，但重复度高。
- **建议修法**：保留两处（一份在人格、一份在手册是刻意的冗余），或者把 `AGENTS.md` 的版本压成一条「与 `SOUL.md` 的『Skill 强制重载规则』一致，以下是补充：」+ 只留那行理由。不影响行为。

### N3 · `chat/AGENTS.md:41–42` 的自我重复（已顺手压缩，登记一下）

- 原文同一句里既说「自称同样用『碧琪』，不说『我……』『我们来……』」，又在下一句说「这句话也是说给先生听的」——在改为第一人称后这句会变成「自称同样用『我』」，与「不说我」直接打架。
- 处理：改写为「这句话也是说给先生听的，自称同样用『我』。」，删掉了与第一人称矛盾的「不说『我……』『我们来……』」限定。这句限定原本就是为了强制第三人称，删除属于任务第 1 条要求，非规则遗失。
