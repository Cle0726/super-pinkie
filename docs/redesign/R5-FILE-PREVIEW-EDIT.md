读写范围（`workbench.mjs` 第 160–174 行）：会话绑定的项目文件夹（没绑就是工作区）里可写；外面的路径**只读参考**（`readOnly: true`），写会被拒：「这个位置可作为参考读取；保存和修改请放在当前项目文件夹里」。无限模式例外。保存带 `baseMtimeMs`，磁盘上被改过会冲突提示（第 1230 行起）。

**结论**：Metre 里文件编辑「已经有」，缺的是**从对话到文件的那一下**——Metre 回答 / 工具结果里提到的文件，用户现在要自己开工作台、在资源管理器里找。主流对照（Claude Desktop「open and edit files」、Zed、Cursor）都是点文件名就打开。

## 二、打算做的（R5 范围）

### 1. 入口
- **回答和工具结果里的文件路径可点**：Metre 的读 / 改文件工具（名单复用 `laolao-metre-cat.js` 的 `READ_TOOLS`（read / workbench_read / code_search …）和 `WRITE_TOOLS`（write / edit / apply_patch / code_edit / multi_edit，第 37 行））结果行上的路径，加一个「打开」签条。点了调 `window.__pinkieWorkbench.open(path)`，在工作台里开标签。
  - 只认工具参数 / 结果里**结构化的路径字段**，不在正文里用正则猜路径（避免误认和点出项目外的东西）。
  - 改文件工具（edit / write）的签条打开后直接进**差异视图**（工作台已有 `pinkie.fs.gitShow` 对比，第 1291 行），看 Metre 改了什么。
- **文件卡（作品库）加「在工作台打开」**：只对路径在当前项目文件夹里的文本 / 代码类作品出现；图片 / PDF / HTML 仍走作品库自己的查看器。
- 现有入口（「工作台」键、⌥⌘B、命令面板）不变。
- 工作台不出现时（视口 < 600px、不在 /chat、开着分屏）：签条改为**只读预览面板**（见 4），不硬把工作台挤出来。

### 2. 只读 / 可写
- **以后端 `readOnly` 为准**，前端不自己判：项目文件夹里可写，外面只读，标签上照工作台现在的只读标记。
- **Metre 这一轮正在改的文件**：回合进行中，若这个文件出现在本轮 edit / write 工具调用里，标签临时只读，顶上一条「Metre 正在改这个文件，这一轮结束后可以编辑」。回合结束后解除，并按磁盘重新读一次（工作台已有的 mtime 检查，第 1272 行）。避免用户和代理同时写同一个文件。
- 用户自己改过、还没存的标签，Metre 改了同一个文件：沿用现有保存冲突提示（`baseMtimeMs`），不新做合并。
- 不做：代理在编辑器里「实时打字」效果；多光标协作。

### 3. 和作品库 / 工作台的关系
- **作品库 = 产出物和它的版本**（快照，可恢复）；**工作台 = 磁盘上的现在**。两者不合并，不复制查看器。
- 「在工作台打开」打开的是**磁盘上的原文件**，不是作品库里的某个快照版本；作品库的版本记录照旧由 `artifacts.mjs` 管。打开前若作品库显示的是旧版本，签条写「打开当前文件（作品库里看的是第 N 版）」。
- 文本 / 代码 → 工作台；图片 / PDF / HTML → 作品库查看器（HTML 继续不同源 iframe）。只读预览面板（下面 4）只是工作台不在时的退路，不和作品库抢。
- 待核实（不在本稿定）：用户在工作台存了作品库里的文件，作品库要不要自动记一版。现在看 `artifacts.mjs` 是按代理产出记版本的，用户手改可能不记；做之前先查清，写在实现 PR 里。

### 4. 大文件 / 二进制
- 照后端现有分类，不新加阈值：
  - `text` ≤ 8 MB → Monaco；`image` ≤ 12 MB → 内联图；
  - `too-large` / `binary` → 工作台现有的卡片（文件名、大小、「用系统默认程序打开」，第 1090 行）。
- **只读预览面板**（工作台不在时）：只开文本和图片，文本只显示前 256 KB 并写「只显示前 256 KB，完整内容请在工作台或系统程序里打开」。需要后端 `pinkie.fs.read` 加一个可选 `maxBytes`（只截读、不改现有默认）；这是本稿唯一的后端改动，要协调者认。
- 二进制不做十六进制视图。

### 5. 窄窗 / 日夜
- 1440、820 都 ≥ 600，工作台在；签条在 820 下只显示图标 + 文件名尾段，悬停给全路径。
- 只读预览面板日夜都走 Metre token（`--metre-surface` / `--metre-line-strong` / `--metre-text`）。

## 三、不做
- 新编辑器、新文件树（工作台已有）。
- 正文里正则识别路径。
- 其他模式（项目 / 学习 / 无限）的签条——先只在 Metre，跑顺了再说。
- 上游 `sessions.files.*`：碧琪的 `pinkie.fs.*` 已覆盖且有项目范围检查，不换。

## 四、分 PR（协调者回「可以做」后）
1. **签条 + 打开**：工具结果路径签条、点了开工作台标签；改文件工具进差异视图。真页面测试：签条只在 Metre 出现、点了标签打开、项目外路径标签只读；反例：其他模式不出签条。pr-shots 1440 / 820 × 日 / 夜。
2. **回合中只读**：本轮在改的文件临时只读 + 回合结束重读。真页面测试带反例（没在改的文件不锁）。
3. **作品库「在工作台打开」+ 只读预览面板**（含 `maxBytes`）：后端单测 + 真页面测试，pr-shots 同上。

每个 PR 只在 Metre 生效，其他模式一个字不动；最多一个后台 monitor，不拿锁、不起浏览器，图全走 pr-shots。
