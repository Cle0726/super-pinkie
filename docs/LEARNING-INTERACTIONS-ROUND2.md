# 第二轮学习交互与模型整理

本轮范围：分步解题、错因对照、英语拆句、MapReduce动手实验、引用跳转；模型按实际端点等级合并，每次打开默认常用模型，最近最多6个。

验收要求：

- 分步题只能按顺序作答，当前步骤先尝试再讲解；完整解法在全部步骤结算后查看。
- 错因对照保留真实作答；引用“你的答案”时只能使用回答中实际出现的片段。
- 拆句先标注再核对；核对前不把示范标签和讲解发给前端；草稿和核对结果可恢复。
- MapReduce支持拖动和点击分桶，结果按实际输入计算；相同key进同桶；未完成分桶不能运行Reduce。
- 题卡引用可跳到已绑定资料位置；历史卡片、320px窄屏、昼夜主题、懒加载与后台释放继续有效。
- 同一模型的等级端点合成一个入口；Lite、Agent、不同版本、不同模态保持独立；所有路由必须来自可用目录。
- 原生等级路由和Max/Ultra的既有增强机制分清；不支持的原生等级不得伪装成支持。
- 每次打开默认常用模型；最多6个最近确认使用的模型，去重，同模型等级变化不占新名额；搜索可找到完整目录。
- 更新前隔离验收，更新后核对服务、实际资源与受保护配置。

## 已实现

- 分步题按顺序提交、逐步核对；全部步骤结算后才展开完整解法。每个步骤保留独立的作答记录。
- 模型结算可提供错因对照；“你的回答”只能引用实际作答中的文字，捏造的引用会被去掉，客观评分不受模型描述覆盖。
- 英语拆句支持自主标注主语、谓语、宾语、表语/补语、从句、修饰与连接成分；核对前隐藏示范标签，核对后逐段查看解析和指代，可恢复或重新标注。
- MapReduce词频实验支持拖动、点击分桶和自动示范；按实际输入统一小写、切词、统计。未按key完成分桶不能运行Reduce，自动示范会被记住，不计为独立掌握。
- 卡片来源按钮复用资料库原文定位与高亮接口，传递实际资料编号、位置和引用文字。
