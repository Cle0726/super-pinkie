## 已实现的使用方式

直接问知识点即可，例如“讲清稳压电路输入和负载改变时会怎样”“74LS161 的异步清零与同步装数有什么区别”“这段 C 程序里 p 和 pp 怎么指向”。模型适合用图时会在当前回复里调用组件，配合简短说明；简单事实、闲聊和明确只要文字时保留文字输出。

- 去掉输入栏里的互动开关和工具胶囊，保留笔记入口。暂停练题不会关闭图解能力；明确要求继续练题时可在对话中恢复。
- 稳压管：电路图、输入/输出曲线、电压与电流、器件与限流电阻功率；输入、负载、稳压值等可直接输入或用滑杆调节。区分未击穿、临界、稳压和功率超限；未给定的参数标成可调示例，不当作器件规格。
- 74LS138：三位选择与三个使能、八路低有效输出、真值表及可选最小项输出。高亮的有效端为低电平，避免误导。
- 74LS151：八个数据位、三位选择、低有效禁止端、Y/W 互补输出及完整表。
- 74LS161：异步清零、同步装数、两个使能、CP 上升沿、15→0 回卷、RCO；提供真实逻辑时序与历史观察。历史观察不改写当前芯片状态。
- C 指针内存图：隔离环境真实编译运行后，显示当前代码行、数组格、指针及二级指针箭头；可逐步观察、点击内存格，原代码收起后仍可修改重跑。显示尾后、未初始化和生命周期结束状态，符号地址不会伪装成进程实际地址。
- 图文说明：左图右文、对比表、点击放大、横竖比例预览。真实图片加载失败时保留文字、支持重试；没有图片时可用内置示意图，比例预览明确标注其性质。

没有重建用户自行维护的考纲地图或资料定位，没有改变模型等级、Ultra/Max、字体特效、主窗口或模式双开布局。

## 修复的底层问题

1. 原来的“暂停互动”分支漏掉了主动展示组件的指令。现在练题偏好与交互讲解分开，讲解能力始终可用。
2. 聊天时间线还会过滤未知组件类型。已同时更新组件识别和缓存，避免工具返回成功但消息里没有图。编译后的聊天模块只改这一处类型列表，其余流式、思考、工具执行、历史和草稿代码逐字保留。
3. 原安装版的部分资源表仍引用旧学习脚本。已按当前安装版增量补齐资源、模块与版本，不从旧 App 副本覆盖。
4. 快速时钟事件按顺序合并、分批保存，并带事件编号去重；未确认的操作本地持久化。保存成功但响应丢失时，刷新恢复不会重复加计数。
5. WebKit 在失败图片上重复赋同一 src 可能不再请求。重试使用新图片元素，并保留原始资源地址。

## 实现边界

稳压模型是直流理想钳位教学模型，实际器件的动态阻抗、温漂、容差和瞬态不作硬件级保证。芯片当前专门实现 74LS138、74LS151 和 74LS161 的功能逻辑，不冒充电气级仿真。

C 内存图基于受限编译器 AST 解释，并与本次真实输出核对；不是完整调试器。暂不支持的函数调用、格式或语法只展示真实运行与原因，不生成假的内存步骤。地址采用对象名和元素偏移表示。

一次模型选型测试通过不代表所有提问都会完美排版。后续按真实学习场景继续补回归案例，不能用“能显示一个控件”代替内容与操作质量。
